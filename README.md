# AIMW App — W0 구현

`AI Marketing AX Workspace`의 W0(필수 MVP) 프런트엔드입니다. 기획 저장소는 이 폴더 밖에 있으며 마크다운 전용으로 유지됩니다.

## 실행

```bash
npm install
npm run dev
npm run build
npm run lint
```

## 구현 범위

- 앱 셸 + S0~S9 10개 라우트 골격
- S0 Collector: 5탭(전체/영상/이미지/블로그/뉴스), 사용자가 입력한 분야·키워드 태그, 공개 범위 수동 수집, 화면 상태 미리보기
- S1~S4: F1~F7 핵심 흐름 샘플, S3 Dry-run 발행
- S5~S7: 독립 모듈 샘플 뷰(예측/권한 배지 포함)
- S8: 분석/제작/수정 3탭, 소스 모드 3종, 제작 유형 6종(기본 미선택), G1~G4 승인 게이트, 권리 확인 dialog, 샷 ID·타임코드 수정, DryRender 플레이스홀더
- S9: 진단 / 키워드·콘텐츠 / 예산·예측 / 취합·개선 4탭, 시뮬레이션 전용 예산 게이지, 예측·신뢰도·모델·기간 배지

## 안전 불변항

- 모듈 연결 기본값은 `연결 안 함`이며, 사용자 클릭 시에만 `ModuleLink`가 생성됩니다.
- 자동 동기화·데이터 복제·외부 API 호출·과금은 없습니다.
- S8은 실제 렌더/변환/합성 없이 메타데이터와 샘플 상태만 다룹니다.
- S9는 실제 집행 없이 시뮬레이션만 수행하며, 지출 상한 0원을 기본값으로 합니다.
- 순위를 약속하는 문구를 화면에 사용하지 않습니다.

## 현재 연결 상태

W0 종료 시점 기준 모듈 링크 0건이 정상입니다. 모듈을 새로 연결할 때마다 기획 문서와 결정 기록을 같은 번들에서 갱신합니다.
