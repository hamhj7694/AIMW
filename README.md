# AIMW App — W0 구현

`AI Marketing AX Workspace`의 W0(필수 MVP) 프런트엔드입니다. 기획 저장소는 이 폴더 밖에 있으며 마크다운 전용으로 유지됩니다.

최신 기획 상태는 [`../aimw-design/CURRENT-STATUS.md`](../aimw-design/CURRENT-STATUS.md)에서 확인하세요.
현재 화면 기준은 [`DESIGN-V2.md`](DESIGN-V2.md), 쉬운 사용 기획은 [`../aimw-design/DESIGN-PLAN-v5-EASE.md`](../aimw-design/DESIGN-PLAN-v5-EASE.md)입니다.

## 실행

```bash
npm install
npm run dev
npm run build
npm run lint
```

## 구현 범위

- 앱 셸 + S0~S9 10개 독립 라우트. 각 모듈은 전용 도구 화면을 쓰되 공통 토큰·헤더·모듈 띠·검상 패널을 공유
- 상단 자연어 작업 도우미: 현재 모듈 문맥 예시 제공. 예시는 입력창에만 채우고 `요청하기`를 눌러야 실행
- S0 Collector: 공개 범위 수집함. 4종 소스 썸네일, 수집 큐, S1 이관 체크
- S1~S4: 레퍼런스 보드, 글쓰기 데스크, 발행 스케줄러, 성과 리포트
- S5~S7: 콘텐츠 라이브러리, 예측 대시보드, 세그먼트 빌더
- S8: 영상 워크벤치. 전체 영상 / 구간(씬) / 프레임(콘티) 선택, 타임라인 드래그, 샷 지정, 3가지 소스 모드, 6가지 제작 모드(기본 미선택), G1~G4 승인, 권리 확인, 범위 지정 수정 이력
- S9: 검색 성장 콘솔. 진단 / 키워드·콘텐츠 / 예산·예측 / 취합·개선 4탭, SERP 예시, 예산 시뮬레이션

## 부분 수정

- 글: 원고 전체 편집 + 드래그 선택 + 줄 셀 선택 + 하이라이트 표시. 선택 범위와 요청 문장을 수정 요청 목록에 기록
- 영상: 전체 / 구간 / 프레임 단위로 `shot_id`와 타임코드를 지정해 수정 요청 기록. 자동 재생성 없음
- 두 모듈 모두 수정 요청은 기록이며 사람이 확인한 뒤에만 다음 단계로 진행

## 안전 불변항

- 모듈 연결 기본값은 `연결 안 함`이며, 사용자 클릭 시에만 `ModuleLink`가 생성됩니다.
- 자동 동기화·데이터 복제·외부 API 호출·외부 AI 호출·과금은 없습니다.
- 자연어 도우미는 화면 이동과 선택값 준비만 합니다. 대화는 저장·전송하지 않습니다.
- 예시 문장 클릭은 입력창 채우기만 수행하며, `요청하기` 누르기 전에는 전송·이동하지 않습니다.
- S8은 실제 렌더/변환/합성 없이 메타데이터와 샘플 상태만 다룹니다.
- S9는 실제 집행 없이 시뮬레이션만 수행하며, 지출 상한 0원을 기본값으로 합니다.
- 비용·입찰·예산 변경은 명시적 동의가 필요하고, 10만원 이상은 2차 확인, 상한 초과 시 실행이 막힙니다.
- 순위를 약속하는 문구를 화면에 사용하지 않습니다.

## 현재 연결 상태

W0 종료 시점 기준 모듈 링크 0건이 정상입니다. 모듈을 새로 연결할 때마다 기획 문서와 결정 기록을 같은 번들에서 갱신합니다.
