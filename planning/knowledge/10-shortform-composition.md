# 10. 숏폼 구성 (Short-form Composition) — 별도 기획

숏폼은 실사의 하위가 아니라 **독립 제작 유형**이다. 세로 캔버스·UI 침범·빠른 훅·사운드 OFF가 기본 전제다.

## 10-1. 공식 사양 (확인된 사실)

### KB-SHF-001 캔버스와 비율
정의: 세로 9:16을 기본으로 한다. TikTok 인피드 광고는 세로 최소 540×960(1080×1920 권장), 가로 16:9 최소 960×540, 정사각 1:1 최소 640×640. YouTube Shorts도 세로 9:16.
효과: 하나의 세로 마스터를 여러 플랫폼에 재사용할 수 있다.
적용: `ProductionMode=short_form`이면 `aspect_ratio=9:16`을 기본값으로 두고, 다른 비율은 사용자 선택으로만 허용.
주의: 가로 영상을 단순 크롭하지 않는다. 재구도 한다.
근거: S15 / A, S16 / A

### KB-SHF-002 세이프 존 원칙
정의: Meta는 상·하·좌·우 가장자리 회피와 디스클레이머의 하단 40% 회피를 공식 안내한다. TikTok은 고정 수치가 아니라 **다운로드 템플릿**을 제공하며, 계정명·캡션·CTA(하단)와 액션 버튼(우측)을 피하게 한다. YouTube 유기적 Shorts의 공식 고정 픽셀 구역은 공개되지 않았다.
효과: 텍스트·가격·로고·얼굴이 UI에 가려지지 않는다.
적용: `SafeZoneOverlay`가 플랫폼별 프리셋을 제공. 공식 원칙은 A등급, 제3자 픽셀은 C등급 배지로 구분.
주의: 플랫폼 스펙은 자주 바뀐다. 분기별 재확인.
근거: S10 / A, S15 / A, S16 / A, S11 / C

### KB-SHF-003 사운드 OFF 기본 전제
정의: 자동재생·음소거 시청을 가정해 자막과 텍스트로도 메시지가 완성되어야 한다.
효과: 음성에만 의존한 광고가 음소거에서 무효가 되는 것을 막는다.
적용: `Shot.copy`(자막)를 필수 필드로 두고, 텍스트 위치를 세이프 존과 교차 검증.
주의: 자막이 너무 많으면 시선이 분산된다. 한 프레임에 핵심 문구 하나.
근거: S12 / C, S10 / A

## 10-2. 구성 패턴 (자체 정리, 가설 포함)

### KB-SHF-004 후크 우선 구조
정의: 첫 1~3초에 질문·단정·결과 노출 중 하나로 시선을 잡고, 곧바로 약속을 지불하며, 짧은 CTA로 닫는다.
효과: 이탈률이 높은 구간에서 메시지를 먼저 전달한다.
적용: `VideoIntent.timing.hook_end`를 필수로 저장. 숏폼 게이트에서 "훅이 세이프 존 안에 있는가" 체크.
주의: 15초 분할(0–3/3–11/11–15)은 C등급 경험치. 실제 계정 데이터로 검증.
근거: S12 / C

### KB-SHF-005 세로 재구도 규칙
정의: 가로 프레임을 그대로 자르지 않고, 인물·제품·텍스트를 세로 중앙 가용 영역에 다시 배치한다. 리딩 라인과 시선 방향도 세로에 맞게 다시 잡는다.
효과: 핵심 요소가 잘리지 않고, 세로 특유의 몰입을 살린다.
적용: `Composition3D.subject_layout[]`를 숏폰 프리셋으로 재생성(기존 레이아웃 자동 덮어쓰기 금지, 새 버전 생성).
주의: 원본 가로 결과를 삭제하지 않는다. 버전으로 남긴다.
근거: S02 / B(구도 원리), S10 / A

### KB-SHF-006 숏폼 전환·리듬
정의: 빠른 하드 컷이 기본이고, 점프 컷을 리듬으로 활용한다. 디졸브·페이드는 시간 경과나 종료에만 제한적으로 쓴다.
효과: speedy한 체감과 정보 밀도를 만든다.
적용: `Storyboard.rhythm_note=metric|rhythmic` 우선. 전환 남용 시 경고.
주의: 리듬만 있고 의미가 없으면 스크롤을 넘긴다. 각 컷이 새 정보를 갖게 한다.
근거: S04 / B, S12 / C

### KB-SHF-007 숏폼 템플릿 예시(스키마 수준)
정의: (a) 후크→증거→CTA 3샷 15초, (b) 문제→해결→비교→CTA 4샷 20초, (c) 리스트형 5컷 30초.
효과: 비전문가가 유형을 선택해 빠르게 콘티를 만들 수 있다.
적용: `VideoTemplate`에 `mode=short_form`, `duration`, `shot_pattern[]`, `safe_zone_preset=meta|tiktok|youtube` 저장.
주의: 템플릿은 복사해서 새 프로젝트에 쓰고, 기존 결과를 자동 수정하지 않는다.
근거: 자체 설계(S12 / C 근거)

## 10-3. 검증 게이트

| 게이트 | 통과 조건 |
|---|---|
| 레퍼런스 서치 | 공개 범위 출처 + provenance + 타임코드(있는 경우) |
| 콘티 | 훅 timecode 존재 + 9:16 재구도 반영 |
| 3D 구도 | 세이프 존 오버레이와 충돌 없음 |
| 애니매틱 | 자막이 음소거 상태에서도 읽힘 |
| 렌더 | 플랫폼 프리셋 선택됨 + "비공식 픽셀" 배지 확인 |

> 실제 플랫폼 업로드·집행은 MVP 범위가 아니다(Dry-run).
