# 04. 편집·전환 (Editing & Transitions)

근거: S04(B, 권리 제한 있음 — 개념 확인만), S14(A, 서지). 원문·표·예시를 복제하지 않고 자체 서술.

### KB-EDT-001 컷 vs 전환의 기본 원칙
정의: 컷은 한 샷에서 다음 샷으로 즉시 바뀌는 것. 전환(디졸브·와이프 등)은 시간이 걸리는 변화다.
효과: 대부분의 컷은 관객이 눈치채지 않게 흘러가고, 이름 붙은 컷은 의도적으로 주의를 끈다. 전환은 더 큰 변화(시간 경과·장소 이동·끝)를 알린다.
적용: `Shot.transition`의 기본값은 `cut`. 전환을 쓸 때는 `rationale` 필수.
주의: 전환을 남용하면 장식처럼 보인다. "그냥 부드럽게"는 되묻기 대상.
근거: S04 / B

### KB-EDT-002 몽타주와 쿨레쇼프 효과
정의: 별개의 이미지를 이어 붙여 단일 샷보다 큰 의미나 시간을 만드는 기법. 같은 얼굴 샷도 앞에 무엇을 두느냐에 따라 굶주림·슬픔·욕망으로 읽힌다(쿨레쇼프 효과).
효과: 의미가 개별 샷이 아니라 샷의 **결합**에서 생긴다는 것을 보여준다.
적용: `Storyboard`에서 샷 순서를 바꾸면 `Revision.affected_scopes`에 `meaning_change` 경고를 넣는다.
주의: 예쁜 샷 나열이 아니라 이야기 비트 단위로 설계한다.
근거: S04 / B, S14 / A(서지)

### KB-EDT-003 아이젠슈테인의 5가지 몽타주 방법
정의: 미터적(고정 길이/박자), 리듬적(샷 안의 움직임), 톤적(명암·형태의 감정), 오버토널(셋의 결합), 지적(이미지 결합으로 개념 생성).
효과: 편집의 리듬과 의미를 의도적으로 설계하는 틀.
적용: `Storyboard.rhythm_note`에 `metric|rhythmic|tonal|overtonal|intellectual` 저장. 음악 없이도 리듬 근거를 남길 수 있다.
주의: 다섯 범주가 상호 배타적이지 않다. 하나만 고르지 않고 주된 방식을 기록.
근거: S04 / B, S14 / A(서지)

### KB-EDT-004 크로스컷 / 평행컷 / 인터컷
정의: 크로스컷은 동시다발 장면을 오가며 긴장을 높인다. 평행컷은 관련된 장면을 나란히 놓아 비교를 유도한다. 인터컷은 같은 사건의 두 부분(전화 통화 양 끝 등)을 잇는다.
효과: 두 흐름이 가까워질수록 샷 길이를 줄이면 긴장이 커진다.
적용: `Storyboard.shots[].timecode`에 A/B 트랙을 구분하는 `strand` 필드 저장.
주의: 각 흐름에 방향·색 등 구분 신호를 줘야 관객이 헷갈리지 않는다.
근거: S04 / B

### KB-EDT-005 컷어웨이 / 인서트
정의: 컷어웨이는 주 동작을 잠시 떠나 정보를 준 뒤 돌아온다. 인서트는 장면 안의 세부(편지, 화면, 손)를 클로즈업한다.
효과: 시간·공간을 조절하고, 축 crossing을 숨기는 중립 컷으로도 쓴다.
적용: `Shot.shot_type=insert|cutaway`. 소품 목록(KB-PRD-003)과 연결.
주의: 소품·조명이 그대로일 때 인서트를 함께 촬영하면 비용이 줄어든다(촬영 팁).
근거: S04 / B

### KB-EDT-006 매치 컷과 사운드 브리지
정의: 두 샷이 모양·색·구도(그래픽 매치), 움직임(액션 매치), 소리(사운드 브리지)를 공유해 연결된다.
효과: 형태나 소리가 다리 역할을 해 컷을 자연스럽거나 의미 있게 만든다.
적용: `Shot.transition=match_graphic|match_action|sound_bridge` 저장. 액션 매치는 움직임 **도중**에 자르도록 `timecode_in` 가이드.
주의: 매치 요소가 약하면 그냥 하드 컷이 낫다.
근거: S04 / B

### KB-EDT-007 J컷 / L컷
정의: J컷은 다음 샷의 소리가 먼저 시작되고, L컷은 이전 샷의 소리가 다음 화면에 이어진다. 이름은 타임라인 트랙 모양에서 온다.
효과: 화면과 소리를 같은 프레임에 자르면 급하게 느껴진다. 몇 프레임만 어긋나도 자연스러워진다.
적용: `Revision.elements[]`에 `audio_offset_frames` 저장. 대화 편집에서 기본 제안.
주의: 소리만 먼저 나오면 혼동될 수 있다. 의미가 통하는지 확인.
근거: S04 / B

### KB-EDT-008 점프 컷 / 인비저블 컷
정의: 점프 컷은 고정된 카메라에서 중간을 잘라내 시간이 튀게 한다. 인비저블 컷은 휩 팬, 어두운 물체가 렌즈를 지나가는 순간 등에 컷을 숨긴다.
효과: 점프 컷은 불안·생략·긴장, 인비저블 컷은 원 테이크 착시를 만든다.
적용: `Shot.transition=jump|invisible` + `rationale` 저장. 연속성 경고(KB-FRM-008)와 함께 체크.
주의: 점프 컷을 실수로 만들지 않도록 30도 규칙을 함께 확인.
근거: S04 / B(개념 확인용), S14 / A(서지)

### KB-EDT-009 디졸브 / 페이드 / 워시
정의: 디졸브는 두 샷이 겹치며 전환, 페이드는 검은색으로 갔다 오거나 나오는 것, 워시는 흰색·특정 색으로 밝아지는 것.
효과: 디졸브는 시간 경과·연결, 페이드는 장면·막·영화의 종료, 워시는 기억·계시를 암시한다.
적용: 길이 가이드(예: 24~48프레임, 짧게 6~12프레임)는 **참고치 C등급**으로 표시하고 사용자 확인 후 저장.
주의: 페이드가 많으면 이야기가 끝난 것으로 오해된다.
근거: S04 / B(개념), 길이 수치는 C

### KB-EDT-010 와이프 / 모프
정의: 와이프는 한 방향·모양으로 화면을 밀어 바꾸고, 모프는 두 클립을 분석해 한 이미지가 다른 이미지로 변하는 것처럼 만든다.
효과: 와이프는 장난기·레트로 스타일, 모프는 인터뷰의 점프를 완화하거나 변신을 만든다.
적용: `transition=wipe|morph`. 모션그래픽 유형(모드)에서 와이프를 브랜드 패턴으로 템플릿화 가능.
주의: 와이프를 한 번만 쓰면 스타일이 아니라 실수처럼 보인다.
근거: S04 / B

### KB-EDT-011 연속성 체크리스트 (편집 관점)
정의: 180도 축 유지, 30도 규칙, 동일 소품의 위치 유지(핫 셋), 컷어웨이로 축 crossing 완화.
효과: 공간 이해가 끊기지 않는다.
적용: `Revision.plan()` 결과에 `continuity_warnings[]` 포함. 샷 순서·타임코드 수정 시 항상 실행.
주의: 의도적 위반은 `rationale`로 덮어쓸 수 있으나 자동 승인하지 않는다.
근거: S04 / B(개념 확인용), S08 / B, S14 / A(서지)
