# 01. 카메라 무빙 (Camera Movement)

근거: S01(A), S06(A). 모든 항목은 자체 서술 요약이며 원문을 복제하지 않는다.

### KB-CAM-001 핸드헬드 (Handheld)
정의: 카메라를 어깨·손·가슴 등에 지지하고 사람이 직접 들고 움직이는 방식. 별도 장비가 가장 적다.
효과: 즉시성·에너지를 주고, 인물의 공황이나 긴장에 동조하는 다큐멘터리적 느낌을 만든다.
적용: `Shot.camera` 값을 `handheld`로 기록하고 `Composition3D.motion_path`에 운영자 이동 경로를 둔다.
주의: 과용하면 멀미를 유발할 수 있다. 차분한 제품 컷에 기본값으로 쓰지 않는다.
근거: S01 / A

### KB-CAM-002 돌리 (Dolly)
정의: 바퀴 달린 플랫폼 위에 카메라를 올려 수평으로 부드럽게 이동시키는 장비. 직선·곡선 레일을 쓴다.
효과: 안정적인 활주 느낌. 아주 느린 접근(크립 인)은 위기·깨달음 순간에 효과적이다.
적용: `camera=dolly`, `motion_path`에 시작/끝 좌표와 속도를 기록. OTS 샷에서 배우가 마크를 놓쳐도 미세하게 돌리로 보정하는 용도도 명시.
주의: 레일 공간과 인력이 필요해 비용 게이지에 반영된다. 좁은 공간에서는 짐벌/슬라이더 대안을 제안한다.
근거: S01 / A

### KB-CAM-003 돌리 줌 (Dolly Zoom / Vertigo effect)
정의: 카메라를 뒤로 빼면서 렌즈를 줌인해(또는 반대로) 피사체 크기는 유지하고 배경 크기만 바꾸는 기법.
효과: 공간이 좁혀지거나 멀어지는 심리적 왜곡(현기증·충격)을 만든다.
적용: `Shot.transition`이 아니라 `camera.effect=dolly_zoom`으로 기록하고, 배경 변화 방향(near/far)을 `visual`에 적는다.
주의: 구현 난이도가 높다. MVP 단계에서는 "참고 기법"으로만 표시하고 결과 보장을 하지 않는다.
근거: S01 / A

### KB-CAM-004 슬라이더 (Slider)
정의: 짧은 레일(보통 8피트 이하) 위에서 한 사람이 빠르게 설치해 쓰는 소형 이동 장치.
효과: 고정된 제품·앉아 있는 인물에 짧고 정교한 이동을 준다. 코너를 살짝 넘어 보는 POV에 적합.
적용: `camera=slider`. 제품 클로즈업의 미세 패닝에 기본 후보로 제안.
주의: 돌리와 구분이 어려우므로 `rationale`에 "짧은 이동/빠른 설치" 이유를 남긴다.
근거: S01 / A

### KB-CAM-005 짐벌 (Gimbal)
정의: 다축 짐벌 헤드가 운영자의 떨림을 상쇄하는 휴대용 안정 장치.
효과: 돌리의 부드러움과 핸드헬드의 기동성을 섞는다. 좁은 공간과 빠른 비선형 추적에 적합. 두 운영자 간 핸드오프로 창문 너머로 카메라를 전달할 수도 있다.
적용: `camera=gimbal`. "좁은 실내에서 따라가" 요청의 1순위 후보.
주의: "핸드헬드처럼 흔들리게" 요청과 충돌한다. 요청에 흔들림 정도가 있으면 되묻는다.
근거: S01 / A

### KB-CAM-006 스테디캠/안정화 장치 (Stabilizer / Steadicam)
정의: 조끼로 무게를 분산하고 스프링 암으로 카메라를 떠 있게 하는 장치. 피벗이 균형점에 있어 부드러운 팬·틸트가 가능하다.
효과: 우아하고 긴 원 테이크, 워크앤톡, 복잡한 군무 동선에 적합. 짐벌보다 크고 더 "떠 있는" 느낌.
적용: `camera=stabilizer`. `duration`이 길고 동선이 복잡하면 우선 제안.
주의: 좁은 공간에서 불리. 수직 가동 범위가 제한적이라는 점을 `rationale`에 남긴다.
근거: S01 / A

### KB-CAM-007 크레인 / 짚 (Crane / Jib)
정의: 긴 암 끝에 카메라를 달아 지상에서 높은 지점까지 원호로 움직이는 장비. 6~12피트급은 짚이라 부른다.
효과: 확립 샷에서 장면 안으로 하강하는 전환, 큰 높이 차이를 한 샷에 담는다.
적용: `camera=crane`, `motion_path`에 높이 프로파일(시작 고도→끝 고도)을 기록.
주의: 차량 탑재형은 안전·허가 문제가 있다. 옥외 촬영 시 체크리스트에 넣는다.
근거: S01 / A

### KB-CAM-008 드론 / 항공 (Drone / Aerial)
정의: 드론·헬리콥터 등 공중 플랫폼에서 짐벌로 촬영하는 방식.
효과: 새의 눈 시점, 빠른 이동 물체 추적, 항공 간 추적, 전환용 광활한 확립 샷.
적용: `camera=drone`. `composition3d`에 고도·방향을 명시.
주의: 비행 규정·낙하 위험이 있어 승인 게이트 전에 별도 확인을 요구한다.
근거: S01 / A

### KB-CAM-009 장비 선택 순서
정의: 대본 → 감독과의 합의 → 예산·계획에 맞는 장비 → 키 그립(grip) 의견 확인 순으로 결정한다.
효과: "예쁜 움직임"이 아니라 이야기에 맞는 움직임을 고르게 한다.
적용: S8 제작 탭에서 장비 후보를 뽑을 때 `rationale`에 이 순서를 반영한 근거를 남긴다. 사용자가 장비를 직접 고르면 근거를 덮어쓰지 않고 사용자 선택으로 표시.
주의: 비용만으로 장비를 단정하지 않는다(등급 C 추정 금액은 참고용).
근거: S01 / A
