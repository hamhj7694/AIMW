# 전문가 지식 베이스 (Expert Knowledge Base)

영상·광고·촬영·편집 전문가의 **개념과 판단 기준**을 AI가 읽고 근거로 쓸 수 있도록 정리한 자체 저작 문서입니다.
로컬에만 존재하는 참고 캡처 자산과는 **완전히 별개**이며, 캡처된 화면·문구·마크업을 복제하지 않습니다. 이 문서는 특정 파일 경로에 의존하지 않고 공개 출처 ID만으로 근거를 추적합니다.

## 1. 이 문서들의 역할

- S8 Video Workbench의 `VideoAnalysisService`(기술 분석), `VideoTermService`(자연어→표준용어), `StoryboardService`(카메라·조명·전환 필드 채움), `RevisionService`(수정 의도 해석)가 참조하는 **도메인 근거 저장소**.
- 사람이 읽을 때와 RAG가 청크로 읽을 때 모두 동일한 구조를 유지한다.
- 모든 항목은 `KB-<도메인>-<번호>` 안정 ID를 가진다. ID는 내용이 바뀌어도 재사용하지 않고, 폐기 시 `deprecated`로 표시한다.

## 3. 항목 작성 규약

모든 `### KB-...` 항목은 같은 5줄 구조를 따른다.

```text
정의:    전문 용어의 의미 (자체 서술, 원문 인용 금지)
효과:    시청자에게 어떤 의미/감정을 전달하는가
적용:    S8 파이프라인에서 어떻게 쓰이는가 (필드명 명시)
주의:    오해·남용·예외·되묻기 트리거
근거:    Sxx / 근거 등급 A·B·C
```

### 근거 등급

| 등급 | 의미 | 사용 규칙 |
|---|---|---|
| **A** | 공식 기관·제조사·표준 사양·공식 플랫폼 헬프 (ASC, Rosco, Meta, ACMI) | 그대로 답변 근거로 사용 가능. 단 요약만. |
| **B** | 전문 교육／업계 가이드, 서지 확인된 교과서 개념 (StudioBinder, In Depth Cine, ArtDepartmental, 교과서 서지) | 근거로 사용하되 "일반적 관행"으로 표현. |
| **C** | 경험칙·비공식 수치·커뮤니티 팁 (픽셀 추정치, 광고 타이밍 경험치) | 반드시 "확인 필요 / A/B 검증"을 붙여 표시. 단정 금지. |

## 4. 권리 정책 (중요)

- **원문 복제·번역·각색 금지.** 이 저장소는 개념을 자체 문장으로 요약하고 출처 ID만 남긴다.
- 특히 `S04 Creative Hut`는 "복제·재게시·번역·각색에 서면 허가 필요"라고 명시한다. 따라서 해당 문서는 **용어 존재 확인과 원전 도서 서지 확보용**으로만 쓰고, 문장 구조·예시·표를 그대로 옮기지 않는다.
- `S10 Meta` 공식 헬프의 **원칙**은 인용 가능하되, 제3자가 추정한 픽셀 수치는 `C등급`으로 분리해 "공식 미확인"을 명시한다.
- 저장소에 포함되지 않는 로컬 캡처 자료는 이 지식 베이스의 근거로 사용하지 않는다(라이선스 미확인 + 경로 의존 배제).

## 5. S8과의 연결

```text
사용자 자연어 입력
  → TermMapping 모호성 해소 (07-term-mapping-ko)
  → KB 항목 근거 첨부 (source_id + tier)
  → 사용자 확인 게이트
  → VideoIntent → Storyboard → 3D 스키마 → 애니매틱 → 단계 렌더
```

- 지식 베이스는 **읽기 전용 참고**다. KB가 렌더를 자동 실행하거나 모듈 간 데이터를 자동 복사하지 않는다.
- 근거 등급이 C인 항목으로는 `VideoIntent`를 확정하지 못한다. 반드시 되묻기 또는 사용자 선택을 거친다.

## 6. 갱신 주기

- 플랫폼 스펙(세이프 존, 비율, 문구 제한): **분기별 재확인**.
- 조명·렌즈 등 장비 사실: **반기별 재확인**.
- 출처 문서가 삭제·유료화되면 `SOURCES.md`에 `상태: 확인 불가`로 기록하고 근거 등급을 한 단계 낮춘다.
