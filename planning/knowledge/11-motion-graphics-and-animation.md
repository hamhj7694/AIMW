# 11. 모션그래픽·애니메이션 (Motion Graphics & Animation) — 별도 기획

실사 촬영 규칙(카메라·조명·세트)을 그대로 쓰지 않는다. 대신 **타이밍·이징·타이포·레이어·루프**를 핵심 축으로 삼는다.

## 11-1. 모션 기본 (Motion System)

### KB-MOT-001 지속시간(duration)
정의: Material Design은 표준 300ms를 제시하고, 모바일 화면 퇴장 예시로 195ms를 든다. NN/g는 대부분의 UI 애니메이션을 100~500ms 범위로, 단순 피드백은 약 100ms로 권장한다.
효과: 짧으면 즉각적, 길으면 존재감이 커진다. 100ms 미만은 인식되지 않고, 500ms 초과는 느리게 느껴진다.
적용: S8 UI 토큰(`duration.instant/fast/standard/slow`)과 모션그래픽 산출물의 `Shot.duration`을 분리. 광고 컷의 지속 시간은 프레임 단위로 별도 관리.
주의: UI 토큰을 영상 산출물에 그대로 적용하지 않는다.
근거: Material(M3) 공식 / A, NN/g / B

### KB-MOT-002 이징(easing)
정의: 가속·감속 곡선으로 움직임의 성격을 정한다. Material은 감속·가속·샤프 곡선을 제시하고, 최신 버전은 물리 기반 모델로 이동했다. Carbon은 부자연스럽거나 산만한 바운스 같은 곡선을 피하라고 안내한다.
효과: 같은 이동도 "부드럽게", "즉각적으로", "탄력 있게" 다르게 읽힌다.
적용: `Composition3D.motion_path[].easing`에 `decelerate|accelerate|sharp|spring` 저장. "부드럽게 등장" → 감속 + 300ms를 후보로 제안.
주의: 장식적인 바운스 남용 금지. 브랜드 모션 가이드가 있으면 우선.
근거: Material 공식 / A, Carbon / B

### KB-MOT-003 레이어와 위계
정의: 배경·중간 요소·전경 타입을 분리하고, 등장 순서와 깊이를 정해 시선을 제어한다.
효과: 정보가 한 번에 쏟아지지 않고 읽히는 순서가 생긴다.
적용: `Composition3D.layers[]`에 `z_index`, `enter_at`, `exit_at` 저장.
주의: 레이어가 많으면 렌더 비용이 늘어난다. 비용 게이지에 반영.
근거: 자체 설계(모션 시스템 일반 원칙)

### KB-MOT-004 키네틱 타이포그래피
정의: 글자를 움직여 의미·리듬·강조를 만든다. 가독성(크기·배경 대비), 감정 톤, 타이밍을 함께 설계한다.
효과: 텍스트가 정보 전달뿐 아니라 분위기와 리듬을 만든다.
적용: `Shot.copy`와 `Shot.typography{font,size,weight,motion,contrast_check}` 저장. 자막 세이프 존 규칙(KB-AD-009)과 동시 검증.
주의: 빠르게 움직이는 텍스트는 가독성이 급격히 떨어진다. 정지 구간을 확보.
근거: School of Motion / Creative Bloq / B~C, 일반 가독성 원칙

### KB-MOT-005 반복과 루프
정의: 숏폼·소셜용 모션은 처음과 끝이 자연스럽게 이어지는 루프가 유리하다.
효과: 반복 재생에서 끊김이 없어 보인다.
적용: `VideoTemplate.loopable=true` 옵션. 루프 게이트에서 첫/끝 프레임 유사도를 체크(Phase B).
주의: 모든 광고가 루프가 필요한 건 아니다. CTA가 끝에 있는 경우 루프가 방해가 된다.
근거: 자체 설계

## 11-2. 애니메이션 원칙 (Animation Principles)

### KB-ANI-001 스쿼시 & 스트레치
정의: 힘에 따라 물체의 형태를 눌리고 늘려 무게와 유연성을 표현한다. 부피가 유지되도록 하는 것이 핵심.
효과: 단단한 도형도 살아 있는 것처럼 느껴진다.
적용: `Composition3D.motion_path[].deform` 저장. 제품 로고 애니메이션에 과용하면 브랜드 훼손.
주의: 브랜드 가이드가 형태 변형을 금지하면 비활성화.
근거: Adobe / NYFA / B

### KB-ANI-002 예상 동작(Anticipation)과 후속 동작(Follow-through)
정의: 주요 동작 전에 반대 방향의 준비 동작을 넣고, 정지 후에도 머리카락·옷·부속물이 조금 더 움직인다. 오버래핑 액션은 부위별 속도가 다름을 뜻한다.
효과: 움직임에 무게와 자연스러움이 생긴다.
적용: `motion_path[]`에 `anticipation_frames`, `follow_through_frames` 저장.
주의: preparing 동작이 길면 템포가 늘어진다. 숏폼에서는 프레임 수를 줄인다.
근거: Adobe / NYFA / B

### KB-ANI-003 스테이징과 포즈 투 포즈
정의: 스테이징은 한 순간에 무엇을 보여줄지 정하는 것. 포즈 투 포즈는 핵심 자세를 먼저 정하고 사이를 채우는 방식, 스트레이트 어헤드는 처음부터 끝까지 연속으로 그리는 방식이다.
효과: 읽기 쉬운 실루엣과 의도된 강조가 생긴다.
적용: `Storyboard`의 포즈 키프레임을 `Composition3D.keyframes[]`로 저장.
주의: 실사 콘티의 샷 사이즈 규칙(KB-FRM-001)과 혼용하지 않는다. 애니메이션은 실루엣 우선.
근거: Adobe / Clip Studio / B

### KB-ANI-004 슬로우 인·슬로우 아웃
정의: 움직임의 시작과 끝을 느리게, 중간을 빠르게 하는 타이밍. 이징 곡선(KB-MOT-002)과 함께 적용한다.
효과: 자연스러운 가속·감속으로 "튀는" 느낌을 없앤다.
적용: `motion_path[].easing=decelerate/accelerate` 조합으로 표현.
주의: 전 구간에 적용하면 둔해 보인다.
근거: Adobe / Clip Studio / B

## 11-3. 모드별 차이

| 유형 | 핵심 축 | 게이트 산출물 | 분석 차원 |
|---|---|---|---|
| 실사 | 카메라·조명·세트 | 콘티 + 3D 구도 + 애니매틱 + 샷 렌더 | 내용 + 기술(촬영) |
| 숏폼 | 훅·세이프존·리듬 | 9:16 콘티 + 세이프존 체크 + 애니매틱 | 내용 + 플랫폼 적합성 |
| 영화 | 구도·조명·색·연속성 | 롱테이크 구도 + 색 팔레트 + 애니매틱 | 기술(시네마토그래피) 강조 |
| 영상(일반) | 정보 전달·브랜드 | 인서트·그래픽 오버레이 콘티 | 메시지 구조 + 가독성 |
| 애니메이션 | 타이밍·실루엣·원칙 | 키프레임 시트 + 애니매틱 | 움직임 원칙 준수 |
| 모션그래픽 | 이징·타이포·레이어 | 모션 스펙 시트 + 타이포 미리보기 | 가독성 + 브랜드 일관성 |

> 실제 모션/애니메이션 렌더 엔진 연결은 Phase B/C. MVP는 스키마·샘플 프리뷰와 체크리스트만 제공한다.
