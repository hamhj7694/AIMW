# REFERENCE-AUDIT — 7개 레퍼런스 통합 감사

작성일: 2026-11-22  
대상: 7개 서비스의 로컬 캡처 분석 결과(저장소 미포함, 읽기 전용·수정 없음)  
전체 인벤토리: 별도 소스 인벤토리(사용자 관리, 555파일 / 258.34MB). 이 문서는 그 자료의 **신뢰도·출처·품질·기능/UX 근거**를 통합한다.  
서술 규칙: 캡처는 이 저장소에 포함되지 않으므로 경로·파일명·링크·스크린샷 위치·"특정 분석 파일에서 참고"·"특정 앱 기능 구현" 서술을 기재하지 않는다. 근거는 **로컬 캡처 분석 결과(저장소 미포함)를 일반 원칙으로 정리**한다.

---

## 0. 감사 방법과 한계 (먼저 읽을 것)

- **출처 판별 원칙**: 브라우저 렌더링 산출물 / 조사 에이전트 기록(보조) / 작업 메타(도구 이력) / 생성 재구성물(Craft Anything 산출, 원본 아님)을 엄격히 구분한다. 생성 재구성물은 원본 캡처로 인용하지 않는다.
- **이미지 직접 판독 불가**: 모델의 이미지 입력 미지원으로 스크린샷을 시각적으로 열지 못했다. 화면 기술은 렌더링 텍스트·구조·레이아웃, 안내 문서, OCR, PNG 헤더/해시에 근거한다. **"보이는 내용"은 렌더링 증거 기반이며 픽셀 직접 관찰이 아님**을 각 서비스에 명시했다.
- **P0 F1~F7 정의**: 부모 세션의 정의를 우선한다 → **F1 레퍼런스 분석 → F2 콘텐츠 기획 → F3 콘텐츠 제작 → F4 검수 → F5 발행 → F6 성과 분석 → F7 개선**. 서브 분석이 임의 매핑한 F ID는 이 정의로 재대조했다.

## 1. 출처 신뢰도 등급

| 등급 | 의미 | 해당 자료(일반 원칙) |
|---|---|---|
| A — 원본 캡처 | 실제 렌더링 결과, 메타 일치 | Snipit/Foreplay/Postiz/Creatify(일부)/Buffer/MONOV의 원본 캡처 |
| B — 보조 증거 | 조사 로그·DOM 분석, 교차 확인 필요 | 조사 기록, 안내 문서, 렌더 텍스트 기반 교차 증거. **Motion 진본 재감사 결과도 B등급** |
| C — 생성 산출물 | Craft Anything 재구성, 원본 아님 | 특정 서비스의 생성 재구성물과 검증 산출물 |
| X — 오귀속/불일치 | 근거로 사용 금지 | 오귀속 캡처 전반(Creatify 오염), Creatify 에이전트 라우트의 오귀속 표기(**재감사에서 Motion 진본 B등급으로 재분류**), MONOV 상태 캡처, Foreplay 오염 가이드, 일부 상태 캡처 |

> **X등급 수정 내용 유지**: 초기에는 Motion 관련 자료를 전부 X(오귀속)로 판정했으나, 재캡처 감사에서 진본이 확인되어 **X → B등급으로 재분류**했다. 오귀속 자료 자체는 여전히 X로 제외한다. 이 수정은 점수 0.00 → 3.70, 순위 편입으로 반영되었고 가중치 변경은 없다.

## 2. 서비스별 감사 요약

### 2-1. Snipit (`Snipit`) — 등급 A
- **출처**: 실제 운영 서비스 마케팅 사이트. 로컬 캡처 분석 결과(저장소 미포함)에서 URL/푸터 메타가 일치.
- **범위**: 홈 + 주요 4개 라우트(검색/브랜드 아카이브/보드/소재 생성). 나머지는 링크만.
- **핵심 근거**: 검색 모드(썸네일·카피 / 장면·대사), 보드/폴더/메모, 브랜드 자동 수집(위닝/A/B/타임라인), 4단계 소재 생성 + 크레딧/빈 상태.
- **품질 문제**: 전 라우트 인증 오류, 이름 없는 컨트롤 다수, H1 중복, 조사 문서 일부 0KB, 빌드 산출 없음(이미지 미열람 + 환경 미비 + 동의 요구).
- **판정**: **F1·F2에 최상 기여**. 발행/승인 UI 없음. 원본 HTML/이미지 복제 금지(클린룸 원칙).

### 2-2. Foreplay (`Foreplay`) — 등급 A(단, 오염 문서는 X)
- **출처**: 실제 운영 서비스 마케팅 사이트 렌더 확인. 4개 라우트(발견/렌즈/스파이더/스와이프).
- **핵심 근거**: 스와이프 파일(저장·태그·공유), 발견 필터, 스파이더 자동 수집·훅 분석, 렌즈 벤치마크/세그먼트 리포트, 브리프.
- **품질 문제**: **모든 좁은 뷰포트에서 가로 스크롤**, 긴 화면 절단, 마케팅 스크립트 오류·인증 실패, 실행 기록 중복, 가이드 문서가 **타 서비스 분석으로 오염**, 증거 누락.
- **판정**: **F1·F6 기여**. 실제 앱/API 응답 없음(마케팅 페이지 한정). 스크립트 이식 금지.

### 2-3. MONOV (`MONOV`) — 등급 A + C 혼재
- **출처**: 실제 운영 서비스. 원본 캡처(A)와 **생성 재구성 산출물(C)**이 공존.
- **핵심 근거**: 제품사진 + 레퍼런스 → 광고이미지 다수 생성, 이미지 편집, 짧은 템플릿 영상, 다열 워크스페이스, 다크 카탈로그.
- **중요 오염**: 일부 상태 캡처의 URL/라벨이 **다른 서비스 것**임 → 해당 서비스 메뉴 근거로 사용 불가. 생성 산출물에 오염 FAQ 반영.
- **생성물 품질**: **약 58% 유사, 28/36 claims 유지**. 단순 복사 빌드, 플레이스홀더 이미지, 인증 실패 다수.
- **판정**: **F3 핵심 기여(패턴만)**. 생성 산출물은 라이선스 미확인+오염+품질 문제로 **직접 재사용 금지**.

### 2-4. Creatify (`Creatify`) — 등급 A(라우트 1개 X→Motion 재분류)
- **출처**: 실제 운영 서비스 마케팅 사이트. 생성 코드는 계획서 형태의 보조 문서뿐.
- **핵심 근거**: URL→영상 흐름, 아바타 유형/감정 태그, 리서치/생성/분석 흐름 + 승인 액션, 템플릿 카테고리, 포맷 4종.
- **품질 문제**: **에이전트 라우트가 실제로는 Motion 진본 캡처** — 초기엔 제외, 재감사로 Motion 진본 재분류. 긴 화면 절단, 로그인 게이트, 상태 라벨/화면 불일치, 중복 헤딩.
- **판정**: **F2·F3·F4(사람 승인 문구) 기여**. API 스펙 없음, UI/정적 인터랙션까지만 재현 가능.

### 2-5. Postiz (`Postiz`) — 등급 A
- **출처**: 실제 운영 서비스. 홈 + 주요 4개 라우트.
- **핵심 근거**: 에이전트/MCP 인증, 다수 채널, 비주얼 캘린더, 자동 반복, 공개 REST API + 웹훅, 애널리틱스, 멀티 브랜드, 팀 역할.
- **품질 문제**: 메인은 스크립트 오류 없으나 **라우트 4개는 콘솔 오류 + 결제 실패**; 상태 데이터 전부 빈 배열; 마퀴 카드 반복; 실제 앱 미캡처.
- **판정**: **F5 핵심, F6 보조 기여**. AGPL-3.0(포크 금지), 자체 호스팅 인프라 필요 → MVP에서는 UI 패턴 + 후속 REST 연동만.

### 2-6. Buffer (`Buffer`) — 등급 A(단, 중복 상태 캡처 제외)
- **출처**: 실제 운영 서비스. 홈 + 주요 3개 라우트(발행/인사이트/커뮤니티). 생성 화면 캡처 실패.
- **핵심 근거**: 발행 주간 캘린더/컴포저, 인사이트 지표 카드·주간 요약, 커뮤니티 인박스, 생성 화면 문구, AI/MCP 안내, 협업/승인.
- **품질 문제**: 생성 화면 캡처 2회 실패 → 문구만 확보. 좁은 뷰포트 상태 2개 해시 동일(라벨만 다름), React 오류, 이름 없는 컨트롤 다수.
- **판정**: **F5·F6·F7(Takeaways→개선) 기여**. 생성 화면 단독 근거 없어 F2 확정 금지.

### 2-7. Motion (`Motion`) — 등급 B (재캡처로 진본 확인)

- **초기 감사 결론(일부 철회)**: Motion으로 수집된 캡처의 내용이 **Motion이 아니라 Creatify**였다. 로컬 캡처 분석 결과(저장소 미포함)의 출처 정보와 해시·치수가 Creatify와 일치했다. 서비스 간 자료 혼동으로 캡처가 뒤섞인 것을 확인했다.
- **초기 판정(철회)**: **F1~F7 실질 기여 0**, 캡처 전면 사용 금지, 기능/UI/토큰 "unknown", 오귀속 라벨 교차 확인 필요.
- **재캡처 재감사**: 로컬 캡처 분석 결과(저장소 미포함)에서 **Motion 진본 캡처가 확인**되었다. 서비스 간 자료 혼동으로 표기가 잘못되었을 뿐이며, 진본 캡처 안내 문구가 Motion 랜딩임을 명시한다.
- **기능 근거**: "AI 기반 크리에이티브 분석", "visual-first 리포트", "자동 그룹화", "주간 모멘텀", "AI 자동 태깅", 외부 ROAS/CPA 연동. **즉 F1·F2·F6·F7에 직접 기여.**
- **토큰**: Inter Variable 계열, 남색/연회색/검정 계열, 라운드 6/18/24/32/10px, 브레이크포인트 479/767/991px. **재선언 허용, 복제 금지**.
- **수정 판정**: 등급 **B**. 오귀속 캡처만 계속 제외하고, 진본 캡처를 **Motion 진본 패턴 근거로 재분류**(이전의 "Creatify 오귀속" 표현은 철회). 단 긴 화면 절단·인증 게이트·API 호출 기록 없음 한계는 유지되어 실제 API 명세나 내부 리포트 동작을 단정하지 않는다.
- **영향**: 조합 점수 Motion 0.00 → **3.70**, 기능 매트릭스·디자인·결정 기록 동기화. 가중치와 다른 서비스 점수는 변경 없음.

## 5. P0 7단계 기여도 재대조 (부모 정의 기준)

| 단계 | 정의 | 1순위 근거 | 2순위 | 비고 |
|---|---|---|---|---|
| F1 레퍼런스 분석 | 레퍼런스 수집·검색·AI 추출 | Snipit(검색/보드/아카이브), Foreplay(발견/스와이프) | Buffer(커뮤니티) | 가장 근거 풍부 |
| F2 콘텐츠 기획 | 브리프·콘셉트·카피 계획 | Snipit(소재 생성 흐름), Creatify(리서치/에이전트) | Foreplay(브리프), Buffer(생성 문구만) | Buffer 생성 화면 누락 주의 |
| F3 콘텐츠 제작 | 이미지·영상 생성 | MONOV(다수 결과/편집/템플릿), Creatify(URL→영상/아바타) | Snipit(소재 생성 UI) | 실제 생성 API 미확인 |
| F4 검수 | 브랜드·정보·카피 검수·승인 | Creatify(승인 전 검토 문구), Buffer(협업/승인) | Postiz(역할) | 전용 근거 부족, 자체 설계 필요 |
| F5 발행 | 채널 변환·예약·상태 | Postiz(캘린더/자동반복/API), Buffer(발행) | — | MVP는 Dry-run |
| F6 성과 분석 | 지표 대시보드·비교 | Buffer(인사이트/Takeaways), Foreplay(렌즈) | Postiz(애널리틱스) | 플랫폼 커버리지 제약 |
| F7 개선 | 개선안→새 브리프 순환 | Buffer(주간 요약), Foreplay(스파이더 리포트) | Creatify(분석) | 순환 버튼은 자체 설계 |

> 재캡처 전에는 Motion 기여 0이었으나, 진본 확인 후 **F1·F2·F6·F7 기여**로 수정했다. 위 매핑은 서브 분석의 임의 F ID를 **F1~F7 실 정의로 재대조**한 결과다.

## 7. 감사 범위 외 — S8/S9/전문 지식베이스 (자체 설계, 레퍼런스 점수 아님)

- **S8 Video Workbench**: 7개 캡처에 대응하는 기능/화면이 없다. 따라서 **자체 설계(레퍼런스 점수 아님)** 로 분류하고, 조합 점수 문서의 2장 점수표·순위에 넣지 않는다. 기존 점수·순위(Motion 4위 3.70, Creatify 5위 3.55, Foreplay 6위, Postiz 7위)는 변경하지 않는다.
- **S8 미디어 소스·변환·합성 확장**: 입력 소스 3종(`generate_new`/`transform_source`/`composite`), 이미지(크롭/색보정/배경 제거·교체/객체 편집/업스케일/스타일 변환), 영상(트리밍/리타이밍/그레이딩/배경 교체/객체 제거/스타일 변환/프레임 보간), 합성(레이어/마스킹/블렌딩/레이어 타이밍)은 **캡처에 근거가 없는 자체 설계**다. `rights_flag`/`rights_confirmed_by` 권한 게이트, before/after, 샘플 단가 기반 비용 미리보기, 기존 4게이트 그대로 통과 원칙도 자체 설계이며 점수·순위에 영향 없다. Phase A는 스키마·샘플·드라이런만, 실제 어댑터·웹서비스형 처리는 Phase B/C 또는 제외다.
- **제작 유형 체계**: 실사/숏폼/영화/영상/애니메이션/모션그래픽 6종 선택은 프로젝트 단위 사용자 명시 선택(기본 미선택, 자동 감지·변경 금지)이다. 캡처 서비스가 제시한 분류가 아니며 **자체 설계**이므로 점수에 영향 없다. 유형별 프로파일은 제작 유형별 명세(별도 관리)의 일반 원칙을 참조한다.
- **레퍼런스 서치 체계**: 자동(사용자 트리거)/수동(URL·메모·타임코드) 이원화와 공개 범위 한정(공식 API·공개 피드·공개 메타·수동; 로그인/유료벽/우회 제외), `ModuleLink(s0→s8)` 클릭 연결만 허용한다. 이 역시 **자체 설계**이며 캡처 점수·순위에 영향 없다. 검색 축 근거는 자체 검색 플레이북(별도 관리)의 일반 원칙을 참조한다.
- **S9 SEO & Search Growth**: **레퍼런스 자료에는 SEO 전용 캡처가 없다.** 진단(기술·온페이지·콘텐츠), 키워드 갭·검색 의도 매핑, 제목/메타/구조 개선안, SERP 추적(공식 데이터 한정), 투자비용↔성과 예측(CPC/CAC/ROAS/유입), 예산 배분 추천, 취합 대시보드, 개선 루프(클릭 기반 `ModuleLink`)는 모두 **자체 설계(레퍼런스 점수 아님)** 다. S9을 캡처 점수표·순위에 **절대 포함하지 않으며**, 기존 7개 서비스 순위도 변경하지 않는다. 공개·공식 범위만 허용하고 스크래핑·로그인 우회·유료벽 우회를 금지한다. Phase A는 수동·샘플·룰·드라이런, Phase B는 공식 API + 회귀, Phase C는 ML·포털 확장이다. S6과 데이터를 복제하지 않는다.
- **전문 지식베이스**: 자체 지식베이스는 공개된 권위 있는 영화·광고 자료를 출처로 **새로 작성**하는 지식이다. 캡처가 아니므로 **캡처 서비스의 증거로 취급하지 않고**, 6장의 "직접 코드 재사용 불가" 원칙(0건)에도 영향하지 않는다. 숏폼·모션그래픽 공식 스펙도 이 새 자체 출처 기반이다(일반 원칙만 참조).
- **출처 경계**: 캡처 마케팅 사이트 문구를 전문 용어의 근거로 등록하지 않는다. Motion 진본(B등급 3.70)과 오귀속 캡처 제외, 직접 코드 재사용 0건은 그대로 유지한다.
- **A6 한계 연장**: 이미지 직접 판독 불가 한계 때문에 프레임 단위 기술 분석을 캡처 스크린샷으로 검증하지 않는다. S8의 분석 스키마는 자연어 입력 + 사용자 확인 기반이며, 타사 레퍼런스 미디어는 메타데이터 전용(프레임 다운로드·분석 금지)이다. 타임코드 Grounding 범위는 별도 확인 사항이다.

## 8. 결론

2026-11-22 사용자 결정으로 **S0 Collector(분야·경쟁사 등록 → 영상/이미지/블로그/뉴스 수집 → 정리 → 분석)는 MVP에 포함**되었으나, 이 기능은 7개 캡처에 대응하는 근거가 없다. 따라서 수집 파이프라인은 자체 설계하고, 캡처는 여전히 UI·인터랙션 참고용으로만 쓴다(자세한 소스/라이선스 근거는 결정 기록의 수집 파이프라인 장 참조).

S0 Collector와 S5~S7 모듈은 **캡처에 대응하는 근거가 없어 자체 설계**한다. S8 비디오 워크벤치(제작 유형·레퍼런스 서치·미디어 변환/합성·권한 게이트 포함)와 S9 SEO & Search Growth, 전문 지식베이스도 **캡처에 대응하는 근거가 없는 자체 설계/자체 저작**이며, 점수·순위에 반영하지 않는다(7장). 본 감사는 모듈의 UI 패턴을 정당화하지 않으며, 필요할 때만 Motion/Snipit/Buffer의 개별 패턴을 참고한다(엉킴 금지).

7개 자료는 **"재사용할 코드"가 아니라 "검증된 인터랙션 패턴과 UI(폰트/토큰/레이아웃)의 근거"**다. 특히 (1) Motion 캡처가 서비스 간 자료 혼동으로 뒤섞여 있었던 출처 오귀속(재캡처로 진본 확인), (2) Creatify↔Motion 라우트 교차 오염, (3) MONOV 생성물의 약 58% 품질+오염, (4) 이미지 직접 판독 불가가 가장 큰 신뢰 리스크다. 오귀속 자료는 명시적으로 제외하고, 진본으로 확인된 자료도 **패턴 참고만** 허용한다. 따라서 설계는 **클린룸 재작성 + 토큰 재선언 + Dry-run** 원칙 위에 세우고, 오귀속 자료는 명시적으로 제외한다. 점수·채택 기준은 조합 점수 문서와 기능 매트릭스에 반영했다.

> **최종 확인**: 직접 코드 재사용 0건, Motion 진본 B등급 3.70(4위), Creatify 3.55(5위), Foreplay 6위, Postiz 7위는 이번 변경에서 불변이다. 저장소 미포함 캡처의 경로·파일명·링크·스크린샷 위치는 이 문서에 존재하지 않는다.
