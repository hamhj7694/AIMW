# FEATURE-MATRIX — 서비스별 기능·UI 채택 매트릭스

작성일: 2026-11-22  
분류 5종: **직접 코드 재사용 / 공식 API·MCP 연동 / UI·UX 패턴 참고 후 자체 구현 / 후속 개발 / 제외**  
근거 규칙: 아래 표의 "근거" 열은 모두 **로컬 캡처 분석 결과(저장소 미포함)를 일반 원칙으로 정리**한 것이다. 캡처는 이 저장소에 포함되지 않으므로 경로·파일명·링크·스크린샷 위치를 기재하지 않는다. 특정 앱의 기능을 그대로 구현한다는 의미가 아니라, 관찰된 일반 패턴을 참고해 **자체 설계·자체 구현**한다는 뜻이다.  
P0 정의: F1 레퍼런스 분석 → F2 콘텐츠 기획 → F3 콘텐츠 제작 → F4 검수 → F5 발행 → F6 성과 분석 → F7 개선.

> **직접 코드 재사용은 전 서비스에서 0건**이다(라이선스 미확인 + 오귀속 + 품질 문제). "UI·UX 패턴 참고 후 자체 구현"이 MVP의 기본 채택 방식이다.
>
> **개정**: 아래 표의 "후속 개발"은 *관찰된 일반 패턴을 자체 설계로 흡수해 나중에 확장하는 것*을 의미한다. 이와 별개로 **자체 수집 파이프라인(S0 Collector)은 MVP에 포함**한다(공식 영상/검색 API + RSS + 공개 뉴스 + 수동, 4개 파트 탭). 또한 **S5 우리 콘텐츠 / S6 성과·예측 / S7 오디언스 세그먼트 / S8 비디오 워크벤치 / S9 SEO & Search Growth**도 캡처에 대응하는 기능이 없어 자체 설계하며, 모듈 간 연결은 사용자 클릭(ModuleLink)으로만 한다. 채택 근거는 조합 점수 문서의 모듈 조합 표 참조.
>
> **S8은 "자체 설계(레퍼런스 점수 아님)"**: 제작 유형 6종 체계, 레퍼런스 서치 체계, 2계층 분석·4단계 게이트·샷 단위 수정, 미디어 소스/변환/합성·권한 게이트·before/after·비용 미리보기는 모두 자체 설계이며 아래 7개 서비스 표·점수·순위에 포함되지 않는다. 전문 지식베이스는 공개 권위 자료로 **새로 저작**한 것으로 캡처 서비스의 증거가 아니다. 숏폼·모션그래픽 공식 스펙도 새 자체 출처 기반이며, 검색 플레이북과 함께 일반 원칙만 참조한다.
>
> **S9은 "자체 설계(레퍼런스 점수 아님)"**: SEO 진단·키워드·집행·예측·취합 체계는 캡처에 대응하는 기능이 없다. **레퍼런스 자료에는 SEO 전용 캡처가 없다.** 따라서 S9을 캡처 점수표·순위에 절대 포함하지 않으며, 기존 순위(Motion 4위 3.70, Creatify 5위 3.55, Foreplay 6위, Postiz 7위)는 변경하지 않는다.

| 데이터 출처 범위 | 소유 확인 계정의 공식 검색 콘솔·광고 키워드 도구, 공식 검색 API, 공개 피드/메타, 수동 입력 | 공식 API·공개 데이터 연동(Phase B) | 스크래핑·로그인 우회·유료벽 우회 금지 |
| 단계 분리 | Phase A 수동·샘플·룰·드라이런 / Phase B 공식 API + statsmodels·scikit-learn / Phase C ML 최적화·포털 확장 | 자체 설계 | 실제 API 호출·쿼터는 Phase B 승인 후 |
| 점수·순위 처리 | 캡처 점수표·순위에 미포함 | 자체 설계 | SEO 전용 캡처 없음, 기존 순위 불변 |

> **점수 미산정**: S9은 **SEO 전용 캡처가 없어** 7개 서비스의 점수표·순위에 포함하지 않는다. S9 기능은 캡처 서비스의 점수를 재해석한 것이 아니라 공개·공식 데이터 범위와 자체 설계 원칙으로 정의한 것이다. "직접 코드 재사용 0건" 원칙도 그대로 유지한다.

## 11. 이 문서의 수용 기준

- [ ] 7개 서비스 모두 표가 존재한다.
- [ ] 각 행의 근거가 로컬 캡처 분석 결과(저장소 미포함)의 일반 원칙으로 서술되고 경로·파일명·링크가 없다.
- [ ] 5개 채택 분류가 모두 사용되었다.
- [ ] 오귀속 캡처, 오염 문서, 중복 상태 캡처가 명시적으로 제외되고, Motion 진본은 B등급 3.70으로 재분류되었다.
- [ ] "직접 코드 재사용 0건"이 일관되게 유지된다.
- [ ] S8(제작 유형 6종·레퍼런스 서치·미디어 소스/변환/합성·권한 게이트 포함)이 "자체 설계(레퍼런스 점수 아님)"로 분리되어 점수표·순위에 포함되지 않는다.

- [ ] 전문 KB가 공개 권위 자료 기반 자체 저작이며 캡처 서비스 근거가 아님을 명시한다.
