# ROADMAP — 올인원 워크스페이스 증분 확장 전략

작성일: 2026-11-22  
범위: **올인원 종합 광고 마케팅 워크스페이스**를 한 번에 만들지 않고, 필수 기능을 먼저 완성한 뒤 나머지 모듈을 조금씩 독립적으로 제작·연결·업데이트하는 진행 방식.  
관련: `PRD.md`, `ARCHITECTURE.md`, `IMPLEMENTATION-PLAN.md`, `DECISION-LOG.md` J장, `design/SEO-GROWTH-SPECS.md`, `design/PRODUCTION-MODE-SPECS.md`

---

## 1. 진행 원칙

1. **필수 우선**: 2일 MVP는 핵심 흐름 완주에만 집중한다. 나머지는 뒤로 미뤄도 제품이 성립하게 만든다.
2. **모듈 단위 증분**: 다음 기능은 항상 **독립 라우트·독립 데이터·독립 테이블**로 추가한다. 기존 모듈을 크게 뜯어고치지 않는다.
3. **기본은 연결 안 함**: 모든 모듈은 단독 진입·단독 동작이 기본값이다. 연결은 사용자가 버튼을 누를 때만 `ModuleLink`로 생성한다.
4. **연결할 때마다 업데이트**: 모듈을 추가하거나 연결을 바꾸면 영향 문서를 같은 번들에서 갱신하고 결정 기록을 남긴다. 문서와 화면이 어긋난 상태로 넘어가지 않는다.
5. **게이트 유지**: 새 모듈도 권한 확인, 예측 배지, Dry-run, 비용·비딩 동의 게이트를 그대로 통과한다. 확장이라고 게이트를 느슨하게 하지 않는다.
6. **불변 항목**: 점수·순위, 경로 독립, 직접 코드 재사용 0건은 어떤 웨이브에서도 바꾸지 않는다.

## 3. 모듈 추가 절차 (새 모듈마다 동일)

- [ ] **1. 독립성 정의**: 라우트·데이터·상태·테이블이 기존 모듈과 공유되지 않는다. 기본값은 "연결 안 함".
- [ ] **2. 명세 작성**: `SCREEN-SPECS.md` / `COMPONENT-SPECS.md`에 반영하거나, S8·S9처럼 별도 명세(`PRODUCTION-MODE-SPECS.md`, `SEO-GROWTH-SPECS.md`)를 만든다.
- [ ] **3. 요구·구조 반영**: `PRD.md`에 FR/NFR 추가, `ARCHITECTURE.md`에 엔티티·엔드포인트·서비스·흐름 추가.
- [ ] **4. 연결 지점 정의**: `ModuleLink(source→target)`의 소스·타깃·사용자 클릭 트리거를 적는다. 자동 동기화·데이터 복제 경로는 만들지 않는다.
- [ ] **5. 문서 동기화**: README 문서 목록, `IMPLEMENTATION-PLAN.md` 작업·체크리스트, `DECISION-LOG.md` 결정 항목을 같은 번들에서 갱신한다.
- [ ] **6. 게이트 확인**: 권한 확인, 예측/샘플/드라이런 배지, 비용·비딩 동의, 접근성, 경로 독립, 점수·순위 불변을 점검한다.
- [ ] **7. 확정 후 착수**: 결정 기록 없이 구현을 시작하지 않는다.

## 4. 연결 업데이트 규칙

- 새 연결은 **데이터를 복사하지 않고 ID 참조만** 한다. 기존 모듈의 테이블을 공유 FK로 묶지 않는다.
- 연결 생성·해제는 모두 사용자 액션이며 `created_by` / `created_at` 이력을 남긴다.
- 연결 때문에 다른 모듈의 화면·데이터 의미가 달라지면 **양쪽 문서에 변경 기록**을 남긴다(한쪽만 고치고 넘어가지 않는다).
- 연결은 언제든 해제할 수 있다. 해제 후에도 두 모듈은 각자 단독으로 동작해야 한다.
- 연결 수가 늘어나도 기본값은 여전히 "연결 안 함". 자동 링크 API는 만들지 않는다.

## 5. 웨이브 완료 기준

- [ ] 해당 웨이브의 모듈이 **독립 라우트로 진입**하고 빈 데이터로도 화면이 열린다.
- [ ] 기본 연결이 0건이고, 연결은 사용자 클릭으로만 생성된다.
- [ ] 화면 4종 상태(빈/로딩/성공/실패)와 예측·샘플·드라이런 배지가 유지된다.
- [ ] 영향 문서(PRD, ARCHITECTURE, SCREEN/COMPONENT-SPECS, IMPLEMENTATION-PLAN, DECISION-LOG, README)가 동기화됐다.
- [ ] 권한·비용 게이트, 경로 독립, 점수·순위, 직접 재사용 0건이 불변이다.
