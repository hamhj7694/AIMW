# 제작 유형 명세 (Production Mode Specs)

S8 Video Workbench의 **프로젝트 단위 제작 유형** 선택 체계. 기존 11개 기획 문서의 S8 확장 문서이며, 캡처 서비스 점수와 무관한 자체 설계다.

## 1. 목적

사용자가 "실사로 찍을지, 숏폼으로 만들지, 영화처럼 연출할지, 애니메이션/모션그래픽으로 만들지"를 **먼저** 고르면, 이후 분석 차원·콘티 필드·게이트·템플릿·세이프 존·비용 게이지가 그 유형에 맞게 바뀐다.

## 2. 유형 정의 (6종)

| 코드 | 이름 | 한 줄 정의 | 기본 비율 | 주요 축 | KB |
|---|---|---|---|---|---|
| `live_action` | 실사 | 사람·사물을 실제 카메라로 촬영 | 16:9(선택) | 카메라·조명·세트·블로킹 | 01~05 |
| `short_form` | 숏폼 | 세로 풀스크린·빠른 훅 중심 | 9:16 | 훅·세이프존·리듬·자막 | 10, 06 |
| `film` | 영화 | 시네마틱 연출·연속성·색 | 2.39:1(선택) | 구도·조명·팔레트·전환 | 01~04 |
| `general_video` | 영상 | 브랜드/정보 전달 일반 영상 | 16:9 | 메시지·인서트·가독성 | 02, 04, 06 |
| `animation` | 애니메이션 | 키프레임·실루엣 중심 움직임 | 16:9 | 타이밍·스쿼시·예상동작 | 11 |
| `motion_graphics` | 모션그래픽 | 타이포·레이어·이징 중심 | 1:1/9:16 | 이징·지속시간·타이포 | 11 |

> 비율은 **기본 제안값**이며 사용자 변경 가능. 유형 자체가 비율을 강제하지 않는다.

## 3. 선택·변경 규칙

1. **기본값 = 미선택.** S8 진입 시 유형을 자동 추정하지 않는다. 미선택 상태에서는 분석/제작 게이트가 잠긴다.
2. **명시적 선택만.** 사용자가 `ProductionModePicker`에서 클릭해야 `VideoIntent.production_mode`가 기록된다.
3. **변경 확인 모달.** 이미 콘티·버전이 있으면 "기존 산출물을 새 버전으로 보존하고 유형을 바꾸시겠습니까?"를 묻는다. 자동 덮어쓰기 금지.
4. **버전 보존.** 유형 변경 시 기존 `Storyboard`/`ShotVersion`은 `archived`로 남고 새 버전이 생성된다.
5. **모듈 독립.** 유형 선택이 S1/S2/S5 데이터를 자동 로드하지 않는다. 필요하면 사용자 클릭으로 `ModuleLink`를 만든다.

## 4. 유형별 상세

### 4-1. 실사 (`live_action`)
- 분석 차원: 내용(훅/메시지/CTA) + 기술(샷사이즈/앵글/무빙/렌즈/조명/구도/전환).
- 콘티 필드: `shot_size`, `camera`, `lighting`, `blocking`, `transition`.
- 3D 구도: 카메라 위치·FOV·피사체 배치·조명 리그·모션 경로(스키마, 실제 렌더 아님).
- 게이트: 콘티 → 3D 구도 → 애니매틱 → 샷 단위 렌더.
- 제약: 타사 프레임 분석 금지(자기 업로드만, Phase B).

### 4-2. 숏폼 (`short_form`)
- 분석 차원: 훅 유형·타임코드·세이프존 충돌·자막 가독성·음소거 이해도.
- 콘티 필드 추가: `hook_type`, `safe_zone_preset(meta|tiktok|youtube)`, `caption_text`, `duration`.
- 게이트 추가: 세이프존 체크(KB-SHF-009 표 참조)를 3D 구도 게이트에 포함.
- 템플릿: 3샷 15초 / 4샷 20초 / 리스트 5컷 30초(KB-SHF-007).
- 제약: 가로 소스의 단순 크롭 금지, 재구도 시 새 버전 생성.

### 4-3. 영화 (`film`)
- 분석 차원: 심도·광비·색 팔레트·연속성(180도/30도)·전환 의미.
- 콘티 필드 추가: `palette[]`, `continuity_warnings[]`, `depth_profile`.
- 게이트 추가: 색 팔레트 승인, 연속성 체크.
- 제약: 돌리 줌·크레인 등 고난도 기법은 "참고 기법" 배지, 결과 보장 안 함.

### 4-4. 영상(`general_video`)
- 분석 차원: 정보 구조·인서트·그래픽 오버레이·가독성.
- 콘티 필드 추가: `overlay_layers[]`, `insert_refs[]`.
- 게이트: 콘티 → 레이아웃 스키마 → 애니매틱 → 렌더.
- 제약: 자막과 오버레이가 겹치면 경고.

### 4-5. 애니메이션 (`animation`)
- 분석 차원: 타이밍·실루엣·예상동작·후속동작·오버래핑.
- 콘티 필드 추가: `keyframes[]`, `deform`, `anticipation_frames`, `follow_through_frames`.
- 3D 구도 대신 **키프레임 시트**를 게이트 2로 사용.
- 제약: 브랜드 가이드가 형태 변형을 금지하면 스쿼시&스트레치 비활성.

### 4-6. 모션그래픽 (`motion_graphics`)
- 분석 차원: 이징·지속시간·타이포 가독성·레이어 위계·루프.
- 콘티 필드 추가: `easing`, `duration_ms`, `typography{motion,contrast_check}`, `layers[]`, `loopable`.
- 게이트 2 = 모션 스펙 시트 + 타이포 미리보기.
- 제약: UI 토큰(100~300ms)을 광고 컷 지속 시간에 그대로 적용하지 않는다.

## 5. 공통 게이트와 유형별 게이트 매트릭스

| 게이트 | 공통 | 실사 | 숏폼 | 영화 | 영상 | 애니메 | 모션그래 |
|---|---|---|---|---|---|---|---|
| G0 레퍼런스 서치 | ✓ | 기법 | 훅/세이프존 | 구도/색 | 메시지 | 타이밍 | 이징/타이포 |
| G1 콘티 | ✓ | 샷사이즈 | 9:16 재구도 | 팔레트 | 인서트 | 키프레임 | 레이어 |
| G2 구도/스펙 | ✓ | 3D 스키마 | 세이프존 | 연속성 | 레이아웃 | 키프레임 시트 | 모션 스펙 |
| G3 애니매틱 | ✓ | 저해상도 | 자막 확인 | 색 확인 | 오버레이 | 타이밍 | 이징 확인 |
| G4 단계 렌더 | ✓ | 샷 단위 | 샷 단위 | 샷 단위 | 샷 단위 | 샷 단위 | 샷 단위 |

- 모든 게이트는 `approved_by`가 없으면 다음 단계를 생성하지 않는다.
- **전체 영상 즉시 생성 버튼은 어떤 유형에서도 제공하지 않는다.**

## 6. 데이터 모델 필드

```text
VideoIntent.production_mode: live_action|short_form|film|general_video|animation|motion_graphics
VideoTemplate.production_mode: 동일 값
VideoTemplate.aspect_ratio, duration, shot_pattern[], transition_policy
Composition3D.mode_schema: camera_rig|safe_zone|continuity|keytframe|motion_spec
RenderStage.gate: G0~G4, approved_by, estimated_cost, estimated_seconds
Revision.production_mode: 수정 요청 시점의 유형(변경 이력 보존)
```

## 7. UI·토큰·접근성

- `ProductionModePicker`: 6개 카드 + "미선택" 상태. 아이콘+한글+영문 병기.
- 색 토큰은 유형별이 아니라 `mode-accent` 하나로 통일, 유형 구분은 아이콘·라벨로 한다(색만으로 구분 금지).
- 변경 확인 모달은 키보드 포커스 트랩, ESC 취소, 스크린리더 안내문 포함.
- "시뮬레이션 배지", "비공식 수치 배지", "Dry-run 배지"를 항상 노출.

## 8. 단계별 범위

| 단계 | 포함 | 제외 |
|---|---|---|
| Phase A | 유형 선택, 유형별 콘티/스키마/애니매틱 **샘플**, 세이프존 오버레이, 체크리스트, 수동 레퍼런스 입력 | 실제 렌더, 실제 3D, 실제 API 호출 |
| Phase B | 공개 API 레퍼런스 검색, 저해상도 렌더 어댑터, 경량 3D 프리뷰, diff 재렌더, 로컬 임베딩 RAG | 대형 모델·고비용 렌더 |
| Phase C | 고품질 렌더 provider, 실제 3D, 개인화 템플릿, CRM 연동(프라이버시 게이트) | 자동 전체 렌더, 무단 모듈 동기화 |

## 9. 수용 기준

- 유형을 선택하지 않으면 G1 이후 진행 불가.
- 유형을 바꿨을 때 기존 산출물이 삭제되거나 덮어써지면 실패.
- 숏폼에서 세이프존 충돌 항목이 있는데 G2를 통과하면 실패.
- 모션그래픽에서 이징/지속시간 필드가 비어 있으면 실패.
- 어떤 유형에서도 "한 번에 전체 영상 생성"이 노출되면 실패.

## 10. 확인 필요

- 유형별 기본 템플릿 소유자(사용자 vs 시스템 프리셋).
- 숏폼 우선 플랫폼(Meta/TikTok/YouTube) 순서.
- 모션그래픽/애니메이션 렌더 엔진 후보와 라이선스·예산.
- 유형 변경 시 기존 산출물 보존 기간.
