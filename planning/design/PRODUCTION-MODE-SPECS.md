# 제작 유형 명세 (Production Mode Specs, 구)

S8 Video Workbench의 **프로젝트 단위 제작 유형** 선택 체계. 기존 11개 기획 문서의 S8 확장 문서이며, 캡처 서비스 점수와 무관한 자체 설계다. 이 문서는 10개 독립 화면 중 S8의 제작 유형·소스 모드 규칙을 다룬다. S9 SEO & Search Growth의 상세 명세는 `SEO-GROWTH-SPECS.md`에 있으며 여기서는 화면 수에만 포함한다. 새 설계 근거는 공개적으로 관찰된 패턴을 자체 원칙으로 재서술하거나 로컬 캡처 분석 결과(저장소 미포함)를 일반 원칙으로 정리한다.

## 1. 목적

사용자가 "실사로 찍을지, 숏폼으로 만들지, 영화처럼 연출할지, 애니메이션/모션그래픽으로 만들지"를 **먼저** 고르면, 이후 분석 차원·콘티 필드·게이트·템플릿·세이프 존·비용 게이지가 그 유형에 맞게 바뀐다.

## 2. 유형 정의 (6종)

| 코드 | 이름 | 한 줄 정의 | 기본 비율 | 주요 축 | KB |
|---|---|---|---|---|---|
| `live_action` | 실사 | 사람·사물을 실제 카메라로 촬영 | 16:9(선택) | 카메라·조명·세트·블로킹 | 01~05 |
| `short_form` | 숏폼 | 세로 풀스크린·빠른 훅 중심 | 9:16 | 훅·세이프존·리듬·자막 | 10, 06 |
| `film` | 영화 | 시네마틱 연출·연속성·색 | 2.39:1(선택) | 구도·조명·팔레트·전환 | 01~04 |
| `general_video` | 영상 | 브랜드/정보 전달 일반 영상 | 16:9 | 메시지·인서트·가독성 | 02, 04, 06 |
| `animation` | 애니메이션 | 키프레임·실루엣 중심 움직임 | 16:9 | 타이밍·스쿼시·예상동작 | 11 |
| `motion_graphics` | 모션그래픽 | 타이포·레이어·이징 중심 | 1:1/9:16 | 이징·지속시간·타이포 | 11 |

> 비율은 **기본 제안값**이며 사용자 변경 가능. 유형 자체가 비율을 강제하지 않는다.

## 3. 선택·변경 규칙

1. **기본값 = 미선택.** S8 진입 시 유형을 자동 추정하지 않는다. 미선택 상태에서는 분석/제작 게이트가 잠긴다.
2. **명시적 선택만.** 사용자가 `ProductionModePicker`에서 클릭해야 `VideoIntent.production_mode`가 기록된다.
3. **변경 확인 모달.** 이미 콘티·버전이 있으면 "기존 산출물을 새 버전으로 보존하고 유형을 바꾸시겠습니까?"를 묻는다. 자동 덮어쓰기 금지.
4. **버전 보존.** 유형 변경 시 기존 `Storyboard`/`ShotVersion`은 `archived`로 남고 새 버전이 생성된다.
5. **모듈 독립.** 유형 선택이 S1/S2/S5 데이터를 자동 로드하지 않는다. 필요하면 사용자 클릭으로 `ModuleLink`를 만든다.

## 3-1. 소스 모드 (InputMode)

제작 유형(`productionMode`)이 **어떤 영상을 만들지**를 정한다면, 소스 모드(`inputMode`)는 **무엇을 재료로 쓸지**를 정한다. 두 값은 독립이며 모두 사용자 명시 선택이다.

| 코드 | 이름 | 의미 | 기본 상태 |
|---|---|---|---|
| `generate_new` | 신규 생성 | 텍스트·레퍼런스·템플릿만으로 새 샷을 만든다 | **기본 표시값** |
| `transform_source` | 기존 미디어 변환·수정 | 업로드·URL·연결된 자산을 변환해 새 샷으로 만든다 | 명시 전환 시 |
| `composite` | 여러 소스 합성 | 여러 소스를 레이어로 겹쳐 하나의 샷·구도 스키마를 만든다 | 명시 전환 시 |

1. **기본값 = `generate_new`.** 자동 감지·자동 전환 금지. 사용자가 선택기를 눌러야만 값이 바뀐다.
2. **전환 확인.** 기존 소스·작업·콘티·샷·버전이 있으면 확인 다이얼로그로 영향 목록을 보여준다. 확정 전 기존 결과를 유지하고, 확정 후에도 이전 버전을 보존한다(덮어쓰기·삭제 없음).
3. **미디어 소스**: 사용자 업로드(자기 콘텐츠), 사용자 제공 URL, S5 기존 자산은 "S8에서 소스로 사용" 클릭 시에만 `ModuleLink(s5→s8)`로 참조한다. 서드파티 레퍼런스는 메타데이터(원문 URL·썸네일 URL·타임코드) 전용이며 프레임을 내려받거나 분석하지 않는다.
4. **권리 게이트**: `transform_source` / `composite`에서는 `rights_flag`와 `rights_confirmed_by`가 확인되기 전 변환·합성 실행 버튼이 비활성이다. 권리 거부 소스는 자동 삭제하지 않고 재확인 경로를 제공한다.
5. **게이트 우회 없음**: 변환된 결과는 `Shot`으로, 합성 레이어는 `Composition3D` 스키마로 들어가 아래 4게이트를 그대로 통과한다. 소스 모드 때문에 게이트를 건너뛰거나 전체 영상을 자동 재생성하지 않는다.
6. **3탭 독립**: 소스 모드와 소스 목록은 분석/제작/수정 탭에 자동 주입되지 않는다. 사용자가 명시적으로 샷·레이어로 지정할 때만 반영된다.

## 4. 유형별 상세

### 4-1. 실사 (`live_action`)
- 분석 차원: 내용(훅/메시지/CTA) + 기술(샷사이즈/앵글/무빙/렌즈/조명/구도/전환).
- 콘티 필드: `shot_size`, `camera`, `lighting`, `blocking`, `transition`.
- 3D 구도: 카메라 위치·FOV·피사체 배치·조명 리그·모션 경로(스키마, 실제 렌더 아님).
- 게이트: 콘티 → 3D 구도 → 애니매틱 → 샷 단위 렌더.
- 제약: 타사 프레임 분석 금지(자기 업로드만, Phase B).
- 변환·합성 가이드: 자기 소스에 색보정·그레이딩과 배경 제거·교체를 우선 적용한다. 객체 편집·업스케일·스타일 변환은 권리 확인과 작업별 예상 비용 확인 후 선택한다. 결과는 샷 단위로 G1 콘티에 투입하고, 조명 리그 스키마(G2)에 반영한다.

### 4-2. 숏폼 (`short_form`)
- 분석 차원: 훅 유형·타임코드·세이프존 충돌·자막 가독성·음소거 이해도.
- 콘티 필드 추가: `hook_type`, `safe_zone_preset(meta|tiktok|youtube)`, `caption_text`, `duration`.
- 사전 확인: 세이프존 체크(KB-SHF-002 표 참조)를 3D 구도 스키마에 반영(승인 게이트 수에는 미포함).
- 템플릿: 3샷 15초 / 4샷 20초 / 리스트 5컷 30초(KB-SHF-007).
- 제약: 가로 소스의 단순 크롭 금지, 재구도 시 새 버전 생성.
- 변환·합성 가이드: 세로 재구도(리사이즈/크롭)와 자막 합성을 기본 조합으로 제안한다. 트리밍·리타이밍으로 훅 구간을 다듬고, 텍스트·로고 레이어는 상·하단 세이프존 안에 배치한다. 레이어 타이밍은 3샷/4샷 템플릿 길이를 따르며 재구도 결과는 항상 새 버전으로 남긴다.

### 4-3. 영화 (`film`)
- 분석 차원: 심도·광비·색 팔레트·연속성(180도/30도)·전환 의미.
- 콘티 필드 추가: `palette[]`, `continuity_warnings[]`, `depth_profile`.
- 사전 확인: 색 팔레트·연속성 체크를 3D 구도 스키마에 반영(승인 게이트 수에는 미포함).
- 제약: 돌리 줌·크레인 등 고난도 기법은 "참고 기법" 배지, 결과 보장 안 함.
- 변환·합성 가이드: 색 팔레트 정규화와 세이프존을 넘지 않는 색그레이딩을 우선한다. 배경 교체·프레임 보간은 연속성(180도/30도) 검토 후 적용하고, 팔레트 승인 전에는 최종 결과로 확정하지 않는다. 여러 소스를 합성할 때도 컷 간 색 연속성을 G2에서 확인한다.

### 4-4. 영상(`general_video`)
- 분석 차원: 정보 구조·인서트·그래픽 오버레이·가독성.
- 콘티 필드 추가: `overlay_layers[]`, `insert_refs[]`.
- 게이트: 콘티 → 레이아웃 스키마 → 애니매틱 → 렌더.
- 제약: 자막과 오버레이가 겹치면 경고.
- 변환·합성 가이드: 인서트 컷과 그래픽 오버레이를 레이어로 합성하고, 배경/인물/제품/텍스트/로고/이펙트 순서를 명시한다. 트리밍·리타이밍으로 정보 전달 리듬을 맞추고 블렌딩은 가독성이 유지되는 범위에서만 허용한다. 오버레이와 자막이 겹치면 경고 후 G3에서 재확인한다.

### 4-5. 애니메이션 (`animation`)
- 분석 차원: 타이밍·실루엣·예상동작·후속동작·오버래핑.
- 콘티 필드 추가: `keyframes[]`, `deform`, `anticipation_frames`, `follow_through_frames`.
- 3D 구도 대신 **키프레임 시트**를 게이트 2로 사용.
- 제약: 브랜드 가이드가 형태 변형을 금지하면 스쿼시&스트레치 비활성.
- 변환·합성 가이드: 레이어 분리와 키프레임 타임코드 정렬을 우선한다. 배경 제거·교체 후 인물/제품 레이어를 재배치하고, 스타일 변환은 실루엣과 예상동작을 해치지 않는 범위에서만 적용한다. 마스킹은 Phase A 가이드 오버레이로만 제공하고, 결과는 키프레임 시트(G2)에 반영한다.

### 4-6. 모션그래픽 (`motion_graphics`)
- 분석 차원: 이징·지속시간·타이포 가독성·레이어 위계·루프.
- 콘티 필드 추가: `easing`, `duration_ms`, `typography{motion,contrast_check}`, `layers[]`, `loopable`.
- 게이트 2 = 모션 스펙 시트 + 타이포 미리보기.
- 제약: UI 토큰(100~300ms)을 광고 컷 지속 시간에 그대로 적용하지 않는다.
- 변환·합성 가이드: 타이포·로고 레이어와 이징 프리셋을 중심으로 합성한다. 텍스트 레이어의 대비·세이프존을 먼저 검증하고, 블렌딩과 레이어 타이밍은 루프 여부를 기준으로 조정한다. 프레임 보간은 이징 곡선을 해치지 않을 때만 사용하며 결과는 모션 스펙 시트(G2)에 반영한다.

## 5. 공통 게이트와 유형별 게이트 매트릭스

| 게이트 | 공통 | 실사 | 숏폼 | 영화 | 영상 | 애니메 | 모션그래 |
|---|---|---|---|---|---|---|---|
| PRE-0a 레퍼런스 서치 | ✓ | 기법 | 훅/세이프존 | 구도/색 | 메시지 | 타이밍 | 이징/타이포 |
| PRE-0b 소스·권리 확인 | 변환·합성 시 필수 | 색보정·배경 권리 | 재구도·자막 권리 | 팔레트·연속성 권리 | 인서트·오버레이 권리 | 레이어·키프레임 권리 | 타이포·이징 권리 |
| G1 콘티 | ✓ | 샷사이즈 | 9:16 재구도 | 팔레트 | 인서트 | 키프레임 | 레이어 |
| G2 구도/스펙 | ✓ | 3D 스키마 | 세이프존 | 연속성 | 레이아웃 | 키프레임 시트 | 모션 스펙 |
| G3 애니매틱 | ✓ | 저해상도 | 자막 확인 | 색 확인 | 오버레이 | 타이밍 | 이징 확인 |
| G4 단계 렌더 | ✓ | 샷 단위 | 샷 단위 | 샷 단위 | 샷 단위 | 샷 단위 | 샷 단위 |

> PRE-0a/0b는 **사전 확인 단계**이며 승인 게이트 수에 포함되지 않는다. 승인 게이트는 G1~G4 **4개**다(J-31).

- G1~G4 승인 게이트는 `approved_by`가 없으면 다음 단계를 생성하지 않는다.
- 변환 결과는 `Shot`으로, 합성 레이어는 `Composition3D` 스키마로 들어가 G1~G4를 그대로 통과한다. 소스 모드에 따라 게이트를 건너뛰지 않는다.
- PRE-0b는 `transform_source` / `composite`에서만 활성이며 `rights_flag` / `rights_confirmed_by` 확인으로 통과한다. 미확인·거부면 G1로 넘어가지 않는다.
- **전체 영상 즉시 생성 버튼은 어떤 유형·소스 모드에서도 제공하지 않는다.**

```text
VideoIntent.production_mode: live_action|short_form|film|general_video|animation|motion_graphics
VideoTemplate.production_mode: 동일 값

MediaSource.rights_flag, rights_confirmed_by, rights_confirmed_at

CompositeLayer.kind: background|person|product|text|logo|effect, blend, timing
TransformPreview.phase: A|B|C, dry_run, sample
```

## 6-1. 소스·권리 규칙

1. **출처 제한**: 소스는 사용자 업로드(자기 콘텐츠), 사용자 제공 URL, S5 자산의 명시적 연결(`ModuleLink(s5→s8)`) 세 경로만 허용한다.
2. **메타데이터 전용**: 서드파티 레퍼런스는 원문 URL·썸네일 URL·타임코드만 보관한다. 프레임 다운로드·프레임 분석·미디어 바이트 저장을 하지 않는다.
3. **사전 확인**: `transform_source` / `composite`는 `rights_flag=true`이고 `rights_confirmed_by`가 기록된 뒤에만 실행할 수 있다. 확인 다이얼로그는 취소 가능하고 취소해도 소스를 삭제하지 않는다.
4. **거부 상태**: 권리 미확인·거부 소스는 작업 버튼이 비활성이고 사유와 재확인 경로를 표시한다. 다른 소스의 작업은 계속 진행할 수 있다(부분 실패 처리).
5. **어댑터 승인**: 실제 변환 어댑터는 공식·라이선스 확인된 공급자 또는 검증된 로컬 도구만 사용한다. 예산·라이선스 승인 후 Phase B/C에서 도입하며 ComfyUI/Blender 웹 서비스는 제외한다.

## 7. UI·토큰·접근성

- `ProductionModePicker`: 6개 카드 + "미선택" 상태. 아이콘+한글+영문 병기.
- 색 토큰은 유형별이 아니라 `mode-accent` 하나로 통일, 유형 구분은 아이콘·라벨로 한다(색만으로 구분 금지).
- 변경 확인 모달은 키보드 포커스 트랩, ESC 취소, 스크린리더 안내문 포함.
- "시뮬레이션 배지", "비공식 수치 배지", "Dry-run 배지"를 항상 노출.
- `InputModePicker`: 소스 모드 3종(신규 생성/기존 미디어 변환·수정/여러 소스 합성)을 제작 유형과 별도로 명시 선택. 기본 `generate_new`, 전환 시 확인 모달과 이전 버전 보존.
- `MediaSourcePicker` / `TransformOperationPicker` / `CompositeLayerPanel`: 소스 카드, 작업 칩, 레이어 행을 제공하고 권리·출처 라벨을 텍스트로 병기한다.
- `MaskingCanvasStub` / `BeforeAfterCompare` / `RightsConfirmationDialog` / `TransformCostPreview`: Phase A 스텁·샘플 비교·권리 확인·작업별 예상 비용을 표시한다. 색만으로 상태를 전달하지 않는다.
- 새 토큰 `s8.source.card`, `s8.rights.badge`, `s8.operation.chip`, `s8.layer.row`, `s8.beforeAfter.split`, `s8.mask.overlay`, `s8.transformCost.preview`는 기존 색상·타입·간격 토큰의 조합만 사용한다.

## 9. 수용 기준

- 유형을 선택하지 않으면 G1 이후 진행 불가.
- 유형을 바꿨을 때 기존 산출물이 삭제되거나 덮어써지면 실패.
- 숏폼에서 세이프존 충돌 항목이 있는데 G2를 통과하면 실패.
- 모션그래픽에서 이징/지속시간 필드가 비어 있으면 실패.
- 어떤 유형에서도 "한 번에 전체 영상 생성"이 노출되면 실패.
- 소스 모드가 `generate_new`가 아니거나 기존 아티팩트가 있는 상태에서 확인 없이 전환되거나 이전 버전이 덮어써지면 실패.
- 권리 미확인·거부 소스로 변환·합성이 실행되거나 서드파티 레퍼런스 프레임이 다운로드·분석되면 실패.
- 변환·합성 결과가 `Shot` / `Composition3D`로 동일 4게이트를 우회하면 실패.
- 어떤 제작 유형·소스 모드에서도 전체 영상 자동 재렌더 버튼이 노출되면 실패.
