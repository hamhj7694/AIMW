# JOURNEYS-V3 — 사용자가 실제로 걷는 길

> 이 문서는 `PRD.md`의 여정을 사용자 눈높이로 다시 쓴 것입니다. 화면 명세는 `design-v3/03-SCREEN-SPECS.md`를 참조하세요.

---

## 원칙

- 사용자는 모듈 번호(S0, S8…)를 보지 않습니다. **하는 일의 이름**을 봅니다.
- 모든 여정의 끝에는 "다음 할 일"이 하나 남습니다. 없으면 "여기까지 완료"라고 씁니다.
- 막히면 왜 막혔는지와 바로 누를 버튼을 함께 보여줍니다.

---

## 여정 1 — 처음 로그인한 날 (온보딩, 3분)

| 단계 | 화면 | 사용자가 보는 문구 | 사용자가 누르는 것 |
|---|---|---|---|
| 1 | 홈 | "먼저 무엇을 찾아볼까요? 키워드 3개면 충분해요." | `키워드 등록` |
| 2 | 살펴보기 · 수집 | "관련 레퍼런스를 한곳에 모으고 있어요." | `결과 보기` |
| 3 | 살펴보기 · 참고 | "잘 먹히는 광고 3개를 골라 보관했어요." | `이걸로 브리프` |
| 4 | 스튜디오 | "브리프가 준비됐어요. 콘셉트 3안 중 하나를 골라 주세요." | `1안 선택` |
| 5 | 홈 | "다음 할 일: 결과 4장 확인" | `결과 확인` |

> 모듈 간 이동은 사용자가 위 버튼을 누를 때만 생깁니다. 자동으로 옮기지 않습니다.

## 여정 2 — 캠페인 한 바퀴 (핵심)

```
[홈] 지금 할 일: 수집 키워드 확인
  ↓ (클릭)
[살펴보기] 경쟁사 콘텐츠 24건 · 저장 3건
  ↓ "이걸로 브리프"
[스튜디오] 브리프 → 콘셉트 3안 → 결과 4장
  ↓ "검수 요청"
[검수] 체크리스트 5개 → "승인하고 큐에 넣기"
  ↓
[발행] 채널별 미리보기 · 예약 (시연)  ← 외부 전송 없음
  ↓
[성과] CSV 업로드 → 지표 매핑 → Top 콘텐츠
  ↓ "개선안 브리프로 보내기"
[스튜디오] 새 브리프에 개선안이 채워짐
```

### 이 여정에서 지킬 것

- 발행 화면에는 항상 **"시연 · 실제 발행 없음"**이 보입니다.
- 승인 버튼은 체크리스트가 끝나기 전에 누를 수 없습니다. 대신 "어떤 항목이 남았는지"를 보여줍니다.
- 개선안을 보낼 때 기존 브리프를 덮어쓰지 않고 새 브리프로 만듭니다.

## 여정 3 — 영상을 말로 요청하기 (v3에서 가장 크게 바뀐 부분)

### 예전 방식 (버린 것)

1. 제작 유형 6종 중 하나 선택 → 2. 소스 모드 선택 → 3. 권한 확인 → 4. 레퍼런스 서치
→ 비전문가가 가장 먼저 전문 용어를 골라야 했습니다.

### 새로운 방식

| 단계 | 화면 문구 | 시스템 행동 | 사용자 행동 |
|---|---|---|---|
| 1 | "어떤 장면이 필요해요? 편하게 적어 주세요." | 자연어 입력 받음 | 문장 입력 |
| 2 | "이렇게 이해했어요. 맞나요?" | 원문/표준용어/근거/신뢰도 표 + 추천 유형 3안 | `이 해석으로 진행` 또는 수정 |
| 3 | "참고할 영상이나 내 파일을 넣을까요?" (건너뛰기 가능) | 선택 사항으로 표시, 권한 확인 배지 | 첨부 또는 `건너뛰기` |
| 4 | "G1 콘티 · 예상 2분 · 0원(시연)" | 미리보기 + 비용/시간 | `다음 단계 진행` |
| 5 | G2 구도 → G3 애니매틱 → G4 샷별 렌더 | 각 단계 동일 패턴 반복 | 매 단계 `진행` 클릭 |
| 6 | "완료. 4개 샷을 확인하세요." | 샷 카드 + 버전 칩 | `한 샷 수정` 또는 `검수로 보내기` |

- 신뢰도가 낮은 항목은 "검증 필요" 배지와 되묻기 카드가 붙습니다. 확인 전에는 제작으로 넘어가지 않습니다.
- 권한 미확인 파일은 조건부로 잠기고, "권한 확인하기" 버튼이 붙습니다.
- 같은 샷만 고치는 요청은 영향 샷 목록을 먼저 보여준 뒤 진행합니다.

## 여정 4 — 우리 콘텐츠가 겹치는지 확인 (독립 모듈)

```
[홈] → [살펴보기 · 우리 콘텐츠]
  → "지난달 만든 '가격 강조' 시리즈와 비슷해요" 배지
  → [시리즈 지정] → [아이디어 백로그에 저장]
  → (선택) "이 아이디어로 기획" → 스튜디오 브리프에 값 채움
```

- 경쟁사 결과를 가져오려면 `참고로 가져오기`를 눌러야 합니다. 자동으로 섞이지 않습니다.

## 여정 5 — 성과와 성장 (독립 모듈)

| 모듈 | 시작 문구 | 다음 할 일 |
|---|---|---|
| 성과 | "CSV를 올리거나 샘플로 둘러보세요." | `샘플로 보기` / `CSV 업로드` |
| 예측 | "지난 6개월 기준 다음 달 추이예요. 예측 · 신뢰도 보통 · 이동평균" | `기간 바꾸기` |
| 오디언스 | "고객 6개 그룹으로 나눠 봤어요. 샘플" | `그룹 선택` |
| SEO 성장 | "제목과 메타 설명 3건을 고쳐 쓸 수 있어요." | `개선안 적용` → `브리프로 보내기` |

- 모든 예측에는 `예측 / 신뢰도 / 모델 / 기간`이 붙습니다. "1위 확정" 같은 문구는 쓰지 않습니다.
- SEO 개선안은 원문을 보존한 채 제안만 표시합니다. 자동 덮어쓰기 금지.
