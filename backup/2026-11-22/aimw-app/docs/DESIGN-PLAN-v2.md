---

## 1. 콘셉트

**라이트테이블 (Light Table)** — 고르고, 승인하고, 내보낸다.

현상한 필름을 콘택트 시트에 올려 프레임을 고르던 행위가 이 제품의 핵심 작업(생성 결과 검토 → 선택 → 승인 → 발행)과 같다.
결과물은 둥근 카드가 아니라 **프레임**이고, 상태는 배지가 아니라 **빨간 펜 자국과 직사각 도장**이다.

---

## 2. 원칙

1. 결과물이 화면의 중심이다. 프레임 그리드가 가장 큰 시각 비중을 갖는다.
2. AI는 상태가 보이는 비동기 작업이다. 대기·진행·완료·실패 네 종류로 제한한다.
3. 사람이 승인한다. 모든 생성 결과는 초안이며, 승인 전 발행은 비활성이다.
4. 한 화면에 주 액션은 하나다. 보조 액션은 캡션·메뉴로 둔다.
5. 출처·모델·비용·게이트를 모든 결과물에 메타로 붙인다.
6. 빈 화면은 다음 행동을 지시한다. "첫 프레임을 올리세요."
7. 토큰과 재사용 컴포넌트만 쓴다. hex 하드코딩 금지.
8. 이모지 아이콘 금지. 선형 도형과 텍스트 라벨을 쓴다.
9. 한국어 UI. 번역투·ALL-CAPS·가운뎃점 메타 금지.
10. 카드 안 카드 금지. 구분선·섹션 헤더·밑줄 탭으로 계층을 만든다.
11. 모듈은 기본 독립. 연결은 사용자 클릭 시 `ModuleLink`로만 생성한다.
12. 실제 집행·과금·외부 호출은 하지 않는다. Phase A는 시뮬레이션·샘플이다.

## 3. 토큰

### 3-1. 색 (Primitives — 전부 변수화, 화면에 hex 직접 금지)

| 토큰 | 값 | 용도 |
|---|---|---|
| `paper` | `#EFF0F2` | 작업대 배경 |
| `sheet` | `#F8F8F7` | 프레임 시트, 패널 |
| `frame` | `#FFFFFF` | 프레임 내부 |
| `ink` | `#14171C` | 제목·본문·주 버튼 |
| `ink-2` | `#3A4048` | 보조 텍스트 |
| `muted` | `#646C77` | 메타·프레임 번호 (대비 4.66:1) |
| `rule` | `#D3D6DB` | 가는 구분선 |
| `rule-strong` | `#A8AEB7` | 강한 경계 |
| `mark` | `#BC3B2B` | 선택 표시·승인 도장·활성 밑줄에만 (대비 4.85:1) |
| `amber` | `#A9761B` | 비용·권리·샘플 맥락에만 |

사용 규칙:
- 배경은 `paper` / `sheet` / `frame` 세 개로 해결한다.
- `mark`는 장식에 쓰지 않는다. 선택·승인·활성·경고 네 가지 의미로만 쓴다.
- 상태색은 채운 배지가 아니라 **도장 테두리와 1~2px 선**으로 표현한다.
- 그라데이션·네온·글래스·보라·청록 없음. 코너 라운드 전역 0.

### 3-2. 타이포

| 토큰 | 값 |
|---|---|
| `font.sans` | Pretendard Variable |
| `font.mono` | JetBrains Mono |
| `type.display` | 46 / 600 / -0.04em |
| `type.heading` | 24 / 600 / -0.03em |
| `type.title` | 19 / 600 / -0.025em |
| `type.body` | 16 / 400 / 1.75 |
| `type.sub` | 13 / 400 / 1.7 |
| `type.meta` | 11 / 400 / mono |

굵기 700 이상 금지. 한글 `word-break: keep-all`. 숫자·타임코드·ID·비용·신뢰도는 mono.

### 3-3. 간격·그리드·반경

| 토큰 | 값 |
|---|---|
| spacing | 4, 8, 12, 16, 24, 40, 64 |
| radius | 0 (예외: Selection mark 타원만 ellipse) |
| app grid | code rail 52px + main 1fr + inspect 250px |
| content max | 1200px |
| gutter | 24px(1440) / 16px(1280 이하) |
| frame grid | 4열, gap 9px |
| 기준 해상도 | 1440×900 |

### 3-4. 모션·아이콘
- hover 120ms, drawer 180ms ease-out. `transition: all` 금지.
- `prefers-reduced-motion`에서 전이 비활성.
- 아이콘은 선형 도형 + 텍스트 라벨. 이모지 금지.

## 7. 흐름 (명시적 클릭만)

1. **S0 검토 흐름**: 소스 등록 → 수집 → 프레임 선택 → 검상 패널 → "S1 References로 이동" 클릭 시 `ModuleLink(s0→s1)`
2. **S8 제작 흐름**: 제작 유형 명시 선택 → 레퍼런스 서치(사용자 트리거) → 소스 모드 선택 → 권리 확인 → G1~G4 → "이 샷만 수정"
3. **S9 시뮬레이션 흐름**: 진단 → 예산·예측(예측/신뢰도/모델/기간 배지) → 취합·개선 → 클릭 시 `ModuleLink(s9→s2|s5)`
4. **비용 확인 흐름(시뮬레이션)**: 예상 비용 표시 → 동의 → 임계치 초과 시 2차 확인 → 이력 기록. Phase A에서는 실행 없음.
