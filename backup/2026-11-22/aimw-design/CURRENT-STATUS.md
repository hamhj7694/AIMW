## 3. 현재 제품 규칙 요약

- 10개 독립 라우트 `/s0`~`/s9`, 기본 `연결 안 함`, 클릭 시에만 ModuleLink.
- Collector 공개 범위만. 로그인·유료벽 우회, 스크래핑, 자동 호출 없음.
- S8: 소스 모드 3종, 제작 모드 6종 기본 미선택, G1~G4, `rights_flag`·`rights_confirmed_by`,
  전체 영상 / 구간(씬) / 프레임(콘티) 범위 지정 수정, `shot_id`·타임코드 기록.
- S9: 4탭, `is_forecast=true`, 소유 계정만, Google 1순위/네이버 2순위, 90일/12개월,
  실제 집행 없음, 기본 상한 0원, 10만원 이상 2차 확인.
- 자연어 도우미: 전체 챗봇 + 모듈별 문맥 예시. 예시는 입력창에만 채우고 `요청하기` 누르기 전에는 실행하지 않는다.
  외부 AI 호출 없음. 대화 미저장. 실제 생성·수정·집행·과금 없음.
- 비용 변경은 명시적 동의, 상한 초과 시 하드 스톱, 승인 로그 100%.
- 토큰 10색, 라이트 전용. 그라데이션·네온·글래스·이모지·카드 안 카드·ALL-CAPS·끝 화살표 금지.

## 4. 갱신 규칙

새 사용성 요구가 들어오면 순서를 지킨다.

1. 이 파일의 현재 진실 표에 문서를 등록한다.
2. 제품 규칙 변경이면 `DESIGN-PLAN-v5-EASE.md` 같은 부록을 새로 만든다. 동결 문서는 수정하지 않는다.
3. 구현 후 `method/IMPLEMENTATION.md`에 검증 결과를, `method/DECISIONS.md`에 결정을 기록한다.
4. 앱의 `DESIGN-V2.md`와 README를 같은 내용으로 맞춘다.
