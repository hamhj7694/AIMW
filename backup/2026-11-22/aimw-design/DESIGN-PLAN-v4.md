# DESIGN-PLAN v4 — 작업기록장 (Work Ledger)

> v2 라이트테이블과 v3 작업지시서는 모두 같은 AI 디폴트(헤어라인 + 모노 마이크로 라벨 + 0 radius)를 공유했다.
> 사용자의 요구로 시각 언어를 통째로 교체한다. 제품 규칙은 그대로 유지한다.

## 1. 한 문장 방향

이 제품은 멋진 대시보드가 아니라 **누가·언제·어떤 근거로 판단했는지 남기는 작업기록장**이다.
따라서 화면은 카드가 아니라 **검은 헤더, 붉은 활성 표시, 번호가 붙은 행**으로 읽힌다.

## 2. 토큰 (10색, 교체)

| 이름 | 값 | 역할 |
|---|---|---|
| paper | `#EBEAE6` | 앱 배경, 장부 종이 |
| sheet | `#F7F6F2` | 행 띠, 패널 배경, 검은 면 위의 글자 |
| frame | `#FFFFFF` | 입력·다이얼로그 |
| ink | `#101216` | 헤더·검상 면·주 액션·굵은 선 |
| ink-2 | `#3D434B` | 2차 텍스트 |
| muted | `#646A72` | 주석 (sheet 대비 5.0:1) |
| rule | `#CFCDC6` | 약한 구획, 검은 면 위의 보조 글자 |
| rule-strong | `#9A9E9F` | 입력 밑줄 |
| mark | `#B03A28` | 활성 모듈·도장·경고 (paper 대비 5.3:1 / 흰 글자 6.0:1) |
| amber | `#8C6514` | 샘플·예측 표기만 |

대비: ink/paper 16.1:1, ink-2/paper 8.9:1, muted/sheet 5.0:1, mark/paper 5.3:1, sheet/ink 16.6:1.

## 3. 타이포그래피

- 본문·제목·라벨: Pretendard Variable. 사람이 읽는 글은 전부 산세리프.
- JetBrains Mono는 ID·타임코드·수치 값에만.
- 제목 42px/800, 섹션 제목 19px/700, 본문 15px/1.75, 주석 12px.
- ALL-CAPS 금지, 가운뎃점 메타 금지, `WORD — fragment` 금지, 버튼 끝 화살표 금지.

## 4. 구조 (v2/v3과 전면 교체)

```
┌──────────────────────────────────────────────────────────┐
│ AIMW  작업기록장     제공자 Ollama (로컬)  예상비용 0원     │  58px 검은 헤더
├──────────────────────────────────────────────────────────┤
│ S0 수집 │ S1 분석 │ S2 브리프 │ … │ S9 검색             │  46px 모듈 띠, 활성=빨간 블록
├──────────────────────────────────────┬───────────────────┤
│ S0 공개 자료                         │ 검상 기록          │
│ 공개 범위 수집                (42px) │ (검은 면)          │
│ 설명...                              │ 연결 0건 / 상한 0원 │
│ ━━━━━━━━━━━━━━━━━━━ 3px              │                   │
│ ■ 수치 띠 (검은 면, 흰 숫자)          │                   │
│ ━━━━━━━━━━━━━━━━━━━ 3px              │                   │
│ │수집 대상 등록│ (굵은 좌측선)         │                   │
│ 01  항목 / 출처 / 상태 / 선택         │                   │
│ 02  항목 / 출처 / 상태 / 선택         │                   │
└──────────────────────────────────────┴───────────────────┘
```

- 좌측 코드 레일과 큰 모듈 번호 장식 제거. 모듈은 상단 가로 띠에서 선택.
- 활성 모듈은 빨간 바탕에 흰 글자. 나머지는 종이 바탕.
- 헤더와 검상 패널은 검은 면. 본문은 따뜻한 종이색. 대비로 구조를 만든다.
- 수치 띠도 검은 면. 값은 흰색 모노 숫자, 상태 표시는 작은 사각 도장.
- 패널은 상자를 만들지 않고 3px 검은 선과 여백으로 구획.
- 카드 0개. 목록은 번호가 붙은 행. 짝수 행은 연한 종이색 띠.
- 배지는 문장 또는 8px 사각 도장. 아이콘은 화면에서 숨김.
- 주 액션은 화면마다 1개. 나머지는 보조 링크.

## 5. 상태와 신뢰

- 승인은 `승인 완료`, 거절은 `보류`, 예측은 `시뮬레이션` 같은 짧은 한글 문장.
- S8 권리 확인은 붉은 도장, G1~G4는 번호 있는 행.
- S9 예산은 숫자와 함께 `추정`, `실제 집행 없음`을 같은 행에 둔다.
- 샘플/예측 라벨은 데이터 옆에, 별도 배지로 띄우지 않는다.

## 6. 금지

그라데이션, 네온, 글래스, 이모지, 둥근 모서리, 그림자, ALL-CAPS, 가운뎃점 메타,
끝 화살표 버튼, numbered marker 남용, 장식용 애니메이션, 다크 모드(단, 검은 헤더·검상 면은 액센트).

## 7. 제품 규칙 (변경 없음)

10개 독립 라우트, 연결 기본값 `연결 안 함`, 클릭 시에만 ModuleLink,
Collector 공개 범위만, S8 G1~G4·권리 플래그·샷 단위 수정,
S9 4탭·`is_forecast=true`·소유 계정·90일/12개월·S6 복제 금지,
비용 변경 명시 동의·2차 확인·기본 상한 0원·하드 스톱.
