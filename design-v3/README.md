## 새 디자인 한눈에

- **콘셉트:** 한 장짜리 작업 지시서. 대시보드 카드가 아니라 규칙선과 작업 행.
- **색 3개:** `paper #E8E9E2` 60%, `ink #202722` 30%, `signal #B8371B` 10%. 명도 파생 4개만 추가.
- **타이포 2개:** 산세리프가 주도. 세리프는 `24`, `G2` 같은 숫자 도장에만.
- **금지:** 카드, 그림자, 알약 배지, 점 그리드, 그라데이션, 가운데점 메타 문자열, 이모지.
- **제품 불변:** 자동 연결 0건, `ModuleLink`는 사용자 클릭으로만, 발행/과금/렌더는 시연, 비용 사전 동의, S8 4게이트 강제, S9 예측 배지와 순위 보장 금지, KB 근거 A/B/C 유지.

## 방법론 출처

가져온 것 — **방식만** 가져왔습니다.

```text
문서 읽기 → 계획 → 환경 프로브 → 토큰 → 기초 보드 → 컴포넌트
→ 화면 → 상태와 흐름 → 수치 검증 → 핸드오프
```

가져오지 않은 것 — **대상 프로젝트의 개성**은 전이하지 않았습니다.

- cinemokhwa의 목화 은유, 필름 그레인, 세리프 대제목, 톤은 쓰지 않습니다.
- GitHub anti-slop 스킬의 크림 배경과 테라코타 예시도 그대로 쓰지 않았습니다. 대신 업종과 무관한 마케팅 운영의 브리프와 검수표에서 색과 구조를 유도했습니다.
- 화면 문구는 기능 라벨과 상태만 씁니다. 업종명, 제품명, "예:" 상황 예시, 데모용 가짜 수치는 넣지 않습니다.
