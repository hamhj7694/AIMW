### 2-1. 목록 규칙

- 활성 항목은 `signal` 2px 왼쪽 선 + 굵은 글자. 배경은 바꾸지 않습니다.
- 그룹 헤더는 붙이지 않습니다. 대신 항목 사이 16px 여백.
- 모듈 ID는 화면에 노출하지 않고 툴팁에만 둡니다.

## 3. 화면별 핵심 블록

### S0 홈

1. 상태 문구: `좋은 오후예요. 지금 할 일이 하나 있어요.`
2. 지금 할 일 작업 행 1개, 주 액션 버튼 1개
3. 진행 중인 작업 3행. 카드가 아니라 규칙선 행
4. 최근 결과 4행. 썸네일 자리 + 버전
5. 우측 열에는 같은 할 일을 반복하지 않고 `왜 다음인가`만 표시

### S1 살펴보기

- 텍스트 탭: `수집`, `참고`, `우리 콘텐츠`
- 수집: 소스 등록 입력 → 채널 필터 행 → 결과 행
- 참고: 검색 + 필터 → 저장된 레퍼런스 행 → 우측 분석 요약
- 우리 콘텐츠: 보관함 표 → 겹침 상태 텍스트 → 시리즈 → 아이디어 백로그
- 주 액션: 탭마다 다름 (`수집 시작`, `이걸로 브리프 만들기`, `아이디어 저장`)

### S2 스튜디오

- 3단계 게이트: `브리프` → `콘셉트` → `결과`
- 브리프: 제목, 타깃, 톤, 필수 문구, 금지어
- 콘셉트: 3개 안을 작업 행으로 나열하고 하나만 선택
- 결과: 4개 결과 행 + `검수 요청`
- 주 액션: 단계별로 하나만 (`콘셉트 만들기`, `결과 만들기`, `검수 요청`)

### S3 영상 워크벤치

- 입력: `어떤 장면이 필요해요? 편하게 적어 주세요.`
- 해석: 원문, 표준용어, 근거 등급, 신뢰도를 표로 보여 줌
- 4게이트: `콘티` → `구도` → `애니매틱` → `샷별 렌더(시연)`
- 각 게이트: 미리보기 면 + `예상 2분, 시연` + `다음 단계 진행`
- 수정: 샷 타임라인 + `이 샷만 수정`
- 주 액션: 현재 게이트의 `다음 단계 진행` 1개

### S4 발행

- 채널 행 4개. 연결됨과 연동 대기는 글자로 구분
- 게시 큐 주간 표
- 채널별 변환 미리보기
- 상시 상태 문구: `시연 화면입니다. 실제 발행은 일어나지 않아요.`
- 주 액션: `승인하고 큐에 넣기`

### S5 성과

- 텍스트 탭: `성과`, `예측`, `오디언스`
- 성과: CSV 업로드 또는 `샘플로 보기`, 수치 띠, 추이, Top 콘텐츠 표
- 예측: 기간 선택, 추이와 예측 밴드, `예측입니다. 신뢰도 보통. 이동평균 기준 6개월.`
- 오디언스: 변수 선택, k=3~6, 프로필 행, `샘플` 상태
- 주 액션: `개선안 브리프로 보내기`

### S6 성장

- 4탭: `진단`, `키워드와 콘텐츠`, `예산과 예측`, `취합과 개선`
- 진단: 제목, 메타, 구조 개선안 행. `원문 보존` 표시
- 키워드: 갭 표와 검색 의도
- 예산과 예측: 시뮬레이션, `예측입니다.신뢰도 보통.룰 기반.시연.`
- 취합: 실제값과 델타, `브리프로 보내기`
- 주 액션: 현재 탭의 다음 분석 또는 `개선안 적용`

### S7 설정

- Provider 상태, 연결 계정(사용자 직접 로그인), 모듈 링크 목록과 해제
- 비용 한도(기본 0원), 2차 확인 임계값, 승인 이력
- KB 용어 사전, 데이터 보관 기간
- 주 액션: `연결 확인` 또는 `한도 저장`

## 4. 상태 모델

| 상태 | 화면 표현 | 예시 문구 |
|---|---|---|
| Empty | 안내 문장 + 버튼 | `아직 모은 콘텐츠가 없어요. 키워드를 등록해 주세요.` |
| Loading | 진행 숫자 + 2px 선 | `진행 숫자와 2px 선` |
| Partial | 성공과 실패 분리 | `3개 중 1개만 실패했어요.` |
| Error | 원인 + 해결 버튼 | `로컬 AI에 연결하지 못했어요.` |
| Success | 결과 + 다음 할 일 | `완료. 다음은 결과 확인이에요.` |

## 5. 흐름 다이어그램

### F1 첫 캠페인

```text
S0 홈 ─클릭→ S1 수집 ─이걸로 브리프 만들기→ S2 ─검수 요청→ S4 발행(시연)
   ↑                                                       │
   └────────── 개선안 브리프로 보내기 ← S5 성과 ←───────────┘
```

### F2 영상 요청

```text
입력 문장 → 해석 확정 → 권한 확인 → G1 → G2 → G3 → G4 → 검수
              ↑ 신뢰도 낮으면 되묻기
```

### F3 독립 진입

```text
S1-c 우리 콘텐츠 ─선택→ S2
S5-b 예측 ─선택→ S1-c
S6 SEO ─선택→ S2 또는 S1-c
```

자동 화면 전환은 0건. 모든 화살표는 사용자 클릭입니다.
