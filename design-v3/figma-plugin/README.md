# AIMW Design v3.1 Generator — Figma 플러그인

Figma에서 실행하면 3색 토큰, 텍스트 스타일, 기초 보드, 컴포넌트 16종, 작업 행 화면, 상태와 흐름, 핸드오프 보드를 생성합니다. **카드·알약 배지·그림자·그라데이션·점 그리드는 생성하지 않습니다.**

## 파일

| 파일 | 역할 |
|---|---|
| `manifest.json` | 플러그인 등록 정보. 빌드 과정 없음 |
| `code.js` | Figma Plugin API 실행 코드. 디자인 값의 단일 원천 |
| `ui.html` | 진행 로그와 수치 검증 결과를 보여주는 패널 |

## 설치 (Figma 데스크톱 앱 또는 웹)

1. Figma 파일을 하나 엽니다. 새 파일을 권장합니다. 페이지 3개를 사용합니다.
2. 메뉴 → **Plugins → Development → Import plugin from manifest…**
3. 이 폴더의 `manifest.json`을 선택합니다.
4. **Plugins → Development → AIMW Design v3.1 Generator** 실행.
5. `디자인 생성` 버튼 클릭.

> 웹 버전에서 개발 플러그인을 쓰려면 데스크톱 앱에서 먼저 import해야 합니다. 조직 계정은 관리자 승인이 필요할 수 있습니다.

| `03 Handoff` | 토큰, CSS 매핑, 컴포넌트, 접근성, 열린 이슈 |

## 실행 후 확인할 것

플러그인 UI의 **수치 검증** 표에서:

- `프레임 넘침` = 0건
- `주 액션 이상` = 0건, 모든 화면의 주 액션 = 1
- `미바인딩 fill` = 0건
- `하드코딩 hex` = 0건
- 산세리프와 도장 세리프가 실제 설치된 폰트로 표시되는지

그 다음 사람이 직접 확인해야 합니다:

- [ ] 한글 텍스트가 잘리지 않음
- [ ] 버튼 라벨이 결과를 말함
- [ ] 화면이 작업 지시서처럼 읽힘
- [ ] 신호색이 튀지 않음
- [ ] 카드, 배지 알약, 이모지가 없음

> 숫자 PASS는 시각 PASS가 아닙니다. 최종 합격은 사람의 육안 확인 게이트입니다.

## 재생성

같은 파일에서 다시 실행해도 페이지와 변수 컬렉션을 재사용합니다. 다만 노드가 중첩될 수 있으므로 재생성 전에 대상 페이지를 비우는 것을 권장합니다.

## 값을 바꾸려면

`code.js` 상단의 `PRIMITIVES`, `SEMANTIC`, `SPACING`, `RADIUS`, `TEXT_STYLES`를 수정하고 `design-v3/01-DESIGN-SYSTEM.md`와 `design-v3/preview/index.html`의 CSS 변수를 같은 값으로 갱신하세요. 문서, 플러그인, 프리뷰 셋 중 하나라도 어긋나면 합격이 아닙니다.
