# 00 — 디자인 방향 v3.1: The Work Order

> 2026-11-22 **전면 재설계 2차.** 직전 안(페트롤+틸+앰버)도, 그걸 바꾼 1차 안(크림+세리프 제목+테라코타)도 사용자가 지적한 "AI 티"에서 벗어나지 못했습니다. GitHub에서 내려받은 `anti-slop-design`, `deslop`, `figma-designer`, `anti-ai-ui` 규칙과 내장 `frontend-design` 스킬의 2패스 자기 비평을 함께 적용해 **작업 지시서** 방향으로 다시 확정합니다. 출처는 `skills/README.md`, 적용 기록은 `06-ANTI-SLOP-AUDIT.md`에 있습니다.

## 1. 한 문장 콘셉트

**"한 장짜리 작업 지시서"** — 대시보드 카드가 아니라, 규칙선과 확인란, 도장으로 정리된 캠페인 제작 지시서.

### 1-1. 왜 또 바꿨는가

| 안 | 문제 | 이번 결정 |
|---|---|---|
| v3.0 페트롤+틸+앰버 | 파란 계열 SaaS, 의미색 5개, 둥근 카드 | 폐기 |
| v3.1 1차 크림+명조 제목+테라코타 | 지금은 "AI가 만든 감성 editorial"의 정형패턴. 세리프 대제목, 얇은 선, 번호 라벨이 또 다른 템플릿 신호 | 폐기 |
| v3.1 최종 **작업 지시서** | 업종과 무관한 마케팅 운영의 실제 사물인 브리프·검수표·게시 지시서에서 출발 | 확정 |

> 교훈: "AI 티 제거" 스킬을 그대로 따라 하는 것도 또 다른 기본값이 될 수 있습니다. 이번에는 스킬의 체크리스트만 도구로 쓰고, **미학은 AIMW 업무 맥락에서 직접 유도**했습니다.

### 1-2. 미학 근거

- 마케팅 운영은 업종에 상관없이 **승인, 게시 시간, 근거 등급**을 다룹니다. 화려함보다 **기록과 확인**이 핵심입니다.
- 실제 업무 사물: 브리프, 검수 체크리스트, 게시 예약표, 작업 대기표.
- 따라서 구조는 **카드가 아니라 행(row)과 선(rule)**, 강조는 **도장(stamp)처럼 신호색 한 번**, 숫자는 **크게 찍힌 인쇄 숫자**로 표현합니다.
- **화면에 업종 이름, 제품명, 브랜드명, 상황 묘사, 데모용 가짜 수치를 넣지 않습니다.** 기능 라벨과 상태만 씁니다. 이게 없으면 화면이 특정 산업용 템플릿처럼 읽히고, 그게 바로 AI 티입니다.

## 2. 색 — 요청대로 3개만, 60 / 30 / 10

사용자 요청 원문: "색은 가능하면 컬러는 거의 3개로 하고 메인 컬러는 60% 서브컬러는 30% 포인트 컬러는 10% 수준으로 하는게 좋아!"

| 비율 | 역할 | 이름 | HEX | 쓰임 |
|---|---|---|---|---|
| **60%** | 메인 | `paper` 복사지 | `#E8E9E2` | 모든 배경, 입력 배경, 패널. 순수 흰색 없음 |
| **30%** | 서브 | `ink` 먹 잉크 | `#202722` | 본문, 제목, 규칙선, 어두운 미리보기 면. 순수 검정 없음 |
| **10%** | 포인트 | `signal` 확인 도장 | `#B8371B` | 주 액션 1개, 현재 게이트, 확인 도장, 딱 하나의 강조 숫자 |

### 2-1. 같은 색의 밝기 파생 (새 색 아님)

| 토큰 | HEX | 정체 |
|---|---|---|
| `ink/70` | `#59625B` | 잉크를 옅게 한 보조 글자 |
| `ink/20` | `#C9CCC3` | 잉크를 아주 옅게 한 1px 규칙선 |
| `signal/soft` | `#EFD9D2` | 신호색을 옅게 한 주의 배경 |
| `paper/alt` | `#DCDDD5` | 종이를 조금 진하게 한 움푹한 면 |

> 파생값은 **명도만** 다릅니다. 파랑, 초록, 보라, 노랑은 없습니다. 오류도 `signal`을 쓰고 `실패`라는 글자와 점선으로 구분합니다. 완료는 `ink` + `완료` 글자입니다. 색만으로 상태를 전달하지 않습니다.

### 2-2. 대비 검증

| 조합 | 비율 | 판정 |
|---|---|---|
| `ink` on `paper` | 12.50:1 | 통과 |
| `ink/70` on `paper` | 5.17:1 | 통과 |
| `signal` on `paper` | 4.77:1 | 통과 |
| `paper` on `signal` | 4.77:1 | 통과 |

### 2-3. 절대 금지

보라, 파랑, 틸, 네온, 그라데이션, 글래스, 순수 `#FFF`/`#000`, 이모지 아이콘, 색상 알약 배지, 3개 동일 카드 그리드, 4개 지표 카드, 점 그리드 장식, 카드 그림자.

## 3. 타이포그래피 — 산세리프 주도, 세리프는 숫자 도장만

| 역할 | 글꼴 우선순위 | 크기 / 행간 | 굵기 |
|---|---|---|---|
| Display | 프리텐다드 → Noto Sans KR | 40 / 48 | 700 |
| H1 | 프리텐다드 → Noto Sans KR | 28 / 36 | 700 |
| H2 | 프리텐다드 → Noto Sans KR | 22 / 30 | 600 |
| H3 | 프리텐다드 → Noto Sans KR | 18 / 26 | 600 |
| Body | 프리텐다드 → Noto Sans KR | 15 / 24 | 400 |
| Body Strong | 프리텐다드 → Noto Sans KR | 15 / 24 | 600 |
| Caption | 프리텐다드 → Noto Sans KR | 13 / 18 | 400 |
| Numeric | 프리텐다드 tabular figures | 13 / 20 | 400 |
| Stamp number | 나눔명조 → Noto Serif KR | 40 / 44 | 700 |

- **타이포 스케일을 9종으로 넓혔습니다.** 스타일이 6종뿐이면 화면이 스펙 시트처럼 밋밋해집니다. Display·H3·Body Strong·Numeric을 추가해 위계를 만듭니다.
- **세리프는 제목에 쓰지 않습니다.** 오직 `1`, `G2`, `v2` 같은 숫자와 도장 라벨에만 씁니다. 그래서 "세리프 대제목"이라는 AI 신호를 피합니다.
- 모노 글꼴은 쓰지 않습니다(글꼴 2개 유지). 숫자는 프리텐다드의 tabular figures 또는 나눔명조 도장.
- 한글 제목은 `word-break: keep-all`. 이탤릭 없음. Display만 자간 -0.02em, H1은 -0.01em.
- 플러그인은 `figma.listAvailableFontsAsync()`로 실제 폰트를 확인하고 대체 결과를 UI에 보고합니다.

## 4. 레이아웃 — 규칙선과 작업 행

### 데스크톱 1440 × 900

```text
┌──────────────────────────────────────────────────────────────┐
│ 워크스페이스          작업 지시서        로컬 AI      비용 0원  │ 56px  ═══
├──────────┬───────────────────────────────────┬───────────────┤
│ 홈       │ ████████████████████████████████  │ 다음 작업      │
│ 살펴보기 │ █  1   수집 결과 확인     [열기]  │ ─────────      │
│ 스튜디오 │ █      새 결과가 도착했어요.      │ 수집 결과 확인  │
│ 영상     │ ████████████████████████████████  │                │
│ 발행     │ 진행 중                           │ 근거            │
│ 성과     │ ───────────────────────────────── │ 1   확인 대기  │
│ 성장     │ 수집        진행 중         대기   │ ── 2px 신호선  │
│          │ 스튜디오    초안         검수 대기 │ 예상 1분        │
│          │ 영상        게이트 2     승인 대기 │ 작업으로 이동   │
├──────────┴───────────────────────────────────┴───────────────┤
│ 시연 화면입니다. 실제 발행은 일어나지 않아요.   자동 연결 0건    │ 28px
└──────────┴───────────────────────────────────┴───────────────┘
     208px              952px                    280px
```

- **먹색 작업 띠가 화면의 중심입니다.** `ink` 배경에 세리프 숫자 `1`을 신호색으로 찍고, 작업 이름과 주 액션을 한 줄에 묶습니다. 이게 없으면 화면이 텍스트 나열로 보입니다.
- **카드 0개, 그림자 0개, 라운드 2px 이하.** 섹션은 1px `ink/20` 선으로만 나눕니다.
- 좌측은 번호가 아닌 **하는 일 이름**입니다. 모듈 ID는 툴팁에만.
- 우측은 카드가 아니라 **세로 규칙으로 구분된 열**입니다. 배경은 `paper` 그대로.
- 도장은 `signal` 2px 왼쪽 선 + 텍스트. 알약 배지 아님.
- 여백: 좌우 28, 섹션 상하 32, 행 간 16.

### 모바일 390 × 844

상단 `지금 할 일` 한 줄 → 작업 행 세로 스택 → 하단 5탭. 가로 스크롤 0, 터치 영역 44px.

## 5. 톤앤매너

- `~해요`, `~해 주세요`. 버튼은 결과가 보이게 씁니다.
- 메타데이터를 `가운데점(·)`으로 이어 붙이지 않습니다. 문장으로 쓰거나 줄을 바꿉니다.
- `시연`은 배지가 아니라 상태 문구입니다. `시연 화면입니다. 실제 발행은 일어나지 않아요.`
- 상태는 글자로 씁니다. `완료`, `검증 필요`, `실패`, `대기`. 신호색 선은 보조입니다.
- 숫자에는 단위와 근거를 붙입니다. `예상 1분`, `확인 대기 1건`.

| 상황 | 문구 |
|---|---|
| 주 액션 | `이걸로 브리프 만들기` |
| 승인 | `승인하고 큐에 넣기` |
| 실패 | `파일을 읽지 못했어요. 열 이름을 확인해 주세요.` |
| 빈 상태 | `아직 모은 콘텐츠가 없어요. 키워드를 등록해 주세요.` |
| 예측 | `예측입니다. 신뢰도 보통. 이동평균 기준 6개월.` |

금지: `혁신적인`, `강력한 AI`, `원클릭 완성`, `1위 확정`, `확인`만 있는 버튼, `A · B · C` 형식 메타 문자열.

## 6. 모션

- 진입은 `opacity`만 120ms. 슬라이드, 스테거, 카드 호버 없음.
- 상태 변경은 120ms 색 전환.
- 진행은 숫자 + 2px 선. 스피너, 스켈레톤 샤머 없음.
- `prefers-reduced-motion`이면 즉시 표시.

## 7. 자기 비평 2패스

| 1패스에서 발견 | 2패스 수정 |
|---|---|
| 크림 배경 + 세리프 대제목 + 테라코타가 또 다른 AI 정형패턴 | 배경을 차가운 복사지 `#E8E9E2`로, 세리프는 숫자 도장으로만 제한 |
| `01 / 02 / 03` 라벨이 실제 순서가 아닌 곳에도 붙음 | 순서가 맞는 게이트에만 번호 유지. 섹션은 이름만 |
| `시연 · 실제 발행 없음` 같은 가운데점 메타 문자열 | 문장으로 변경 |
| 여전히 3개 콘셉트 카드, 4개 지표 카드가 남음 | 카드를 없애고 작업 행과 수치 띠로 변경 |
| 신호색이 버튼, 배지, 강조숫자에 동시에 들어감 | 주 버튼 1개와 현재 게이트 1개로 제한 |
| 우측 패널에 카드 테두리 | 제거하고 왼쪽 1px 선만 유지 |

최종 질문: 이 화면을 AIMW 운영자에게 보여주면 "광고 회사 대시보드"가 아니라 "내 작업 지시서"로 보이는가? → 예. 구조가 견적서와 검수표에서 왔기 때문입니다.
