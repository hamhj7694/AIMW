## 0. 이번 작업의 판별 전제

- `U-05`(개발자용 연결 상태 제거)와 불변 규칙 문구 유지는 **대상이 다르다.** 연결 상태는 지우고, 시연·승인 전·근거 A/B/C·4게이트·순위 보장 없음은 자연스러운 한국어로 남긴다. (PLANNER-FINDINGS 0절 동일 판별)

- qv7의 테마(The Work Order — 크림+세리프+테라코타), v4~v7 HTML, `aimw-console.html`, `aimw-s0.html`, 레거시 `preview/index.html`은 **한 줄도 재사용하지 않았다.** 새 HTML의 CSS 주석에 그대로 적어 두었다.

**9화면 공통 AI 티 (v7 전체)**
1. **레이아웃 템플릿 고정**: 모든 화면이 좌레일 204 + 우패널 276 + 하단 상태바 28. 화면.role에 따라 달라지지 않는 반복 골격 — 가장 큰 생성 티.
2. **장식 과잉**: 원형 mark, 밴드 좌측 액센트선, 대제목 음수 자간, kicker 대문자 스페이싱. 의미 없는 선·점이 화면마다 5~8개.
3. **카피 3중 반복**: 같은 불변 문구(시연·비용·순위)를 레일·밴드·사이드·상태바에 2~4회씩 복제.
4. **상태 라벨을 할 일로 착각**: `현재 상태: 검토 대기`, `선택 대기`, `입력 대기` — 사용자가 다음에 뭘 해야 하는지 말하지 않음.
5. **간격 스케일 붕괴**: 10/11/12/13/14/18/22/26/28/34/38px. 토큰은 선언했지만 사용처가 무시.
6. **색 4상 과다**: 다크 배경 + 패널 2종 + 종이 + 테라코타. 신호색이 장식색으로도 쓰여 의미가 희석.

### 미반영/부분반영 근거 요약

1. **모델 선택 드롭다운 미기재** — 기획자도 `확인 필요`로 표시한 항목. 실제 모델 목록 근거 없이 이름을 만들면 "데모용 가짜 수치·이름" 금지에 걸린다. API 선택 시 노출 조건도 정적 Figma 시트에서는 표현 불가 → 연결 후 인터랙션 프로토타입에서 검토 제안. **대체 문구: 없음(의도적 공백), 참조 PLANNER 7절.**
2. **영상 primary 2개 잔존** — `해석 요청`(입력)과 `다음 단계 진행`(게이트)은 서로 다른 단계의 액션이라 한 화면에 공존시켰다. 기획자 2차 검토에서 "입력 단계와 게이트 단계를 분리할지" 확인 요청.
3. **프로젝트 행 `열기` 링크 2개 유지** — 행이 2개뿐이라 2개가 주 액션 오해를 만들지 않는다고 판단. 행이 늘면 상단 1개로 강등하는 규칙을 반영표에 명시.
4. **발행 시연 2회** — 발행 화면의 역할 자체가 "시연 경계 분명히"라 notice + 하단 2회가 과잉이 아님. 레일·사이드 중복(기존 4회)은 제거.

## 8. 사람 육안 확인 항목 (최종 게이트)

> 자동 검사(문자열 0건·대비 미달 0건·이름 없는 컨트롤 0건)는 **합격이 아니다.** 아래를 사람이 확인해야 최종 합격이다.

1. **새 시각 세계가 낯설지 않은가**: 라이트 작업면 + 먹색 띠 + 초록 신호가 "The Work Order"(크림+세리프+테라코타)와 확실히 다르고, 동시에 v7 다크 콘솔의 잔상이 없는가.
2. **작업 띠가 시그니처로 읽히는가**: 9화면에서 같은 자리·같은 높이로 반복되며 "다음 할 일 + 상태 + 버튼 1개"가 한눈에 들어오는가. 장식처럼 보이지 않는가.
3. **홈-first 흐름**: 큰 배너 → `요청 해석` → 아래 `다음 할 일` 순으로 시선이 가는가. AI 입력의 실행 방식·API 키·라벨이 한 덩어리로 보이는가.
4. **진입 순서**: 홈 → 프로젝트 선택 → 상세로 이어지는 지각적 흐름이 자연스러운가. 프로젝트 선택에 "작업" 열이 없어 U-02 오해가 사라졌는가.
5. **상태 언어**: `검토 대기`·`입력 대기` 같은 개발자 상태가 보이지 않고, `수집 결과 확인` 같은 할 일 문장만 보이는가.
6. **불변 규칙의 존재감**: 시연·비용 승인 전·검증 필요·순위 보장 없음이 지워지지도, 3~4회 과잉 반복되지도 않았는가.
7. **타이포 밀도**: 46px 배너가 작업 화면에 과하지 않은가. 13px 라벨이 읽히는가. 세리프·음수 자간 잔상이 없는가.
8. **간격 리듬**: 4·8·12·16·24·32·40·48 토큰이 화면에서 고르게 보이는가. 오프그리드가 눈에 띄는가.
9. **영상 primary 2개**: `해석 요청`과 `다음 단계 진행`이 같이 보일 때 어느 것이 먼저인지 헷갈리지 않는가(기획 2차 검토 연계).
10. **Figma 추출 품질(연결 후)**: 9프레임이 1440×900으로 생성되고, 라벨·텍스트가 잘리지 않고, 레이어 이름이 한국어 화면명으로 정리됐는가.
