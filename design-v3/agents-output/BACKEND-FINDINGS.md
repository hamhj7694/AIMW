## 0. 검증 기준 — 제거 targets와 유지 targets를 분리한다

사용자 지적(U-05)과 SURVEY-FINDINGS 3절의 판별 질문을 그대로 적용했습니다.

> **판별 질문:** "이 문구가 사라지면 사용자가 지금 할 일을 못 하거나, 결과를 오해하는가?"
> → **예**: 유지(오해 방지 고지) / → **아니오**: 제거(개발자용 상태).

| 구분 | 대상 문구 | 처리 |
|---|---|---|
| **제거 targets** (개발자용 연결 상태) | `로컬 AI 연결됨`, `연결됨`, `연결 안 됨`, `연동 대기`, `연결 상태`, `모듈`, `모듈 링크 3개`, `자동 연결 0건`, `모든 링크는 클릭으로 생성`, 하단 `로컬 실행 · 마지막 저장` | v8에 **0건**. 레거시 파일에서 복사 금지 |
| **유지 targets** (제품 불변 고지) | `시연 · 실제 발행 없음`, `비용 승인 전 / 매번 확인`, `근거 A/B/C`, `4게이트 강제`, `순위 보장 없음`, `계정 직접 확인` | **유지**하고 자연스러운 한국어로 다듬기 |

**핵심 경계:** `ModuleLink`·자동 연결 0건은 *행동 규칙*이지 *화면 문구*가 아닙니다. 화면에서는 "참고로 보내기를 누를 때만 값이 전달됩니다"처럼 **사용자 행동 → 결과** 문장으로만 말합니다. 반대로 "연결은 클릭으로만", "나중에 붙일 모듈" 같은 로드맵 설명은 화면에 노출하면 안 됩니다(SURVEY V4).

**v7 현 상태 한 줄 판정:** 07감사 52행대로 v7 `index.html`에는 금지 문자열(모듈/연결됨/자동/예:/S0~S9)이 **0건**입니다. 문제는 레거시 파일(`preview/index.html`, `aimw-console.html`, `aimw-s0.html`)과 문서(`03-SCREEN-SPECS.md` 49·215행, `00-DESIGN-DIRECTION.md` 106행, `02-IA-AND-FLOWS.md` 79·104행, `05-HANDOFF.md` 55행)에 여전히 남아 있다는 점입니다. v8 설계자는 이들을 **참고도 복사 금지**해야 합니다.

## 4. AI 모델 / API 키 입력 흐름 ↔ PRD 자격증명 제약 검증

### 결론: **충돌 없음.** 단, 아래 3가지 조건을 v8에서 지켜야 합니다.

**PRD 불변 제약 4 원문:** "계정 로그인/OAuth는 사용자가 직접. 자격증명 대리 입력 금지." (8절) / "FR-54~56 사용자 직접 로그인" (7절)

| 확인 항목 | v7 증거 | 판정 |
|---|---|---|
| 키를 **시스템이 대신 입력**하는가? | 08화면 502행 `<input type="password">`에 사용자가 타이핑. 자동 주입·기존 값 채우기 UI 없음 | 통과 |
| 키가 **화면에 노출**되는가? | `type="password"` + 506행 `입력한 키는 화면에 그대로 표시하지 않습니다.` | 통과 |
| 누가 입력했는지 명시되는가? | 511행 `키 입력 / 사용자 입력` | 통과 |
| 계정 로그인을 시스템이 대행하는가? | 05화면 387행 `계정은 소유자가 직접 확인합니다.` | 통과 |

**v8에서 반드시 지킬 조건:**
1. **마스킹 입력 유지** — `type="password"`와 "화면에 그대로 표시하지 않습니다" 문구를 없애지 않습니다.
2. **자동 입력 금지** — `자동 채우기`, `기억하기`, `기본 키`, `연결됨`(키가 이미 들어있다는 뜻으로 읽히는 문구)을 추가하지 않습니다. 키는 매번 사용자가 넣습니다.
3. **요청 흐름 접근 보장** — 홈(00)에는 모델 선택만 있고 키 입력이 없습니다. 설정(08)에서 직접 입력하게 하는 것은 규칙에 맞지만, SURVEY V6 실패 신호("설정에만 있고 요청 흐름에서 접근 불가")를 피하려면 **영상 워크벤치(04)에 모델 선택 + `API 키 입력·변경` 링크**를 추가해야 합니다(V-1). 링크로 이동한 뒤에도 키 입력은 사용자가 직접 합니다.

> ⚠️ PRD 불변 4는 *"연결됨/연결 안 됨" 상태를 보여라"*라는 뜻이 **아닙니다**. 오히려 그 반대로, 계정·키 상태를 개발자 라벨로 노출하지 않고 "소유자가 직접 확인합니다"라고 행동으로 안내하는 것이 PRD와 U-05를 동시에 만족합니다.
