## 3. "사용자에게 중요한 정보인가?" — 개발자용 상태 UI 걸러내기

U-05의 판단 기준을 재사용 가능한 규칙으로 고정했습니다.
**판별 질문: "이 문구가 사라지면 사용자가 지금 할 일을 못 하거나, 결과를 오해하는가?"**
→ 예: 사용자 정보 / → 아니오: 개발자용 상태이므로 제거.

|---|---|---|---|
| 다음 할 일 / 지금 해야 할 단 하나 | **예** | 유지·강화 | U-03 (정상화) |
| "시연 · 실제 발행 없음" | **예** — 외부 전송 오해 방지 | 유지 (카피만 자연스럽게) | U-03, PRD 불변 3 |
