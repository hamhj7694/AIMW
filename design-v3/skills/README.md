## 적용 원칙

- 스킬의 **미학예시 색상값은 그대로 쓰지 않습니다.** 업종에 묶이지 않는 마케팅 운영이라는 작업 맥락에서 우리 색을 다시 정의했습니다.
- 체크리스트는 `design-v3/06-ANTI-SLOP-AUDIT.md`에 우리말로 옮겨 적용 결과를 기록했습니다.
- 내장 `frontend-design` 스킬의 2패스 비평으로 1차 재설계안(크림+세리프 대제목+테라코타)도 폐기했습니다. 이 스킬은 저장소에 복사하지 않았습니다.
- 스킬에 있는 이미지/스크린샷은 저장하지 않았습니다(저작권·용량). 마크다운 규칙만 보관했습니다.
