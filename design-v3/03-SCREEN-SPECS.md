# 03 — 화면 명세 v3.1

> Figma 프레임은 데스크톱 `1440 × 900`, 모바일 `390 × 844`. 프레임 간격 120px.
> 모든 수치는 `figma-plugin/code.js`의 정의와 일치합니다. 카드가 아니라 작업 행과 규칙선을 씁니다.
> **화면의 모든 문구는 기능 라벨과 상태만 사용합니다.** 업종명, 제품명, "예:" 형태의 상황 예시, 데모용 가짜 데이터는 넣지 않습니다.

  요청 02         표준 용어 02      KB B         높음
  요청 03         표준 용어 03      KB C         확인 필요
  ────────────────────────────────────────────────
  G1 콘티 ─ 완료   G2 구도 ─ 현재   G3 애니매틱   G4 렌더(시연)
  [어두운 미리보기 면: 구도 와이어프레임]   예상 2분, 시연

## 상태 보드

| 상태 | 제목 | 안내 문구 |
|---|---|---|
| Empty | 아직 모은 콘텐츠가 없어요 | 키워드를 등록해 주세요. |
| Loading | 진행 숫자와 2px 선 | 숫자와 2px 선 |
| Partial | 3개 중 1개 실패 | 성공한 3개는 그대로 둘게요. |
| Error | 로컬 AI 연결 실패 | 서버를 켠 뒤 다시 시도해 주세요. |

플로우 보드 3장: F1 첫 캠페인, F2 영상 요청, F3 독립 진입. 각 화살표에 `클릭` 라벨.
