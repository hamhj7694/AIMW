## 적용한 수정

- `--faint` → `#838D9F` (가장 밝은 패널 `#1A2230`에서도 4.77:1). 종이 헤더 전용 `#616875` (4.97:1) 분리.
- `::placeholder`에 `--faint` 적용 → 5.65:1.
- 입력 라벨 3개를 실제 텍스트로 추가(모델과 요청 / 요청 문장 / 찾을 내용).
- 간격을 4·8·12·16·24·32px 스케일로 정리, 폰트는 12/13/14px 중심으로 축소.
- 밴드·알림의 장식용 액센트선 제거, 알림은 상단 1px 구분선으로 변경.
- 홈 '다음 작업' 밴드 삭제 → 잘림 해소 + 중복 제거.
- 포커스 아웃라인 3px로 강화.

Lighthouse 잔여 지적은 `main landmark 없음`, `meta description 없음`, `robots.txt 없음`입니다. 이 HTML은 Figma Code Layer 업로드용 9화면 시트이므로 SEO 항목은 적용 대상이 아니고, `main` 랜드마크는 Figma 추출 시 불필요한 프레임을 만들 수 있어 넣지 않았습니다.

## 의도적으로 유지한 것

- 다크 운영 콘솔 방향은 사용자가 "지금 나쁘진 않은데"라고 확인한 방향이므로 X7(다른 디폴트로 갈아타기)를 피하기 위해 유지했습니다.
- `01~04`, `G1~G4`는 순서가 실제로 있는 단계라 Y11의 '의미 없는 번호'에 해당하지 않습니다.
- 상태 문구는 제품 불변 규칙(시연, 승인 전, 근거, 순위 보장 없음)을 그대로 노출합니다.

## 합격 게이트

자동 검사는 여기까지입니다. **최종 합격은 사람 육안 확인으로만 결정합니다.** 홈 화면 스냅샷을 `figma-import/v7/audit-home.png`에 저장해 리뷰 pane에 띄웠습니다. 전체 9화면 확인 후 피드백 주시면 그대로 반영하겠습니다.
