# AIMW 라이트테이블 — 디자인 v2 (완전 신규)

> 기존 앱 화면·CSS·라우트는 수정하지 않습니다. 이 폴더는 별도 디자인 산출물입니다.
> 레퍼런스: Vercel·Linear(절제와 상태 우선), Attio(AI 네이티브 대시보드), Air·Fabric·Foreplay(크리에이티브 워크플로), Wanted 디자인 시스템(한국어 타이포).

---

## 1. 브랜딩

| 항목 | 내용 |
|---|---|
| 제품명 | **라이트테이블** (Light Table) |
| 한 줄 포지셔닝 | **고르고, 승인하고, 내보낸다.** |
| 범주 | 크리에이티브 운영 작업실 |
| 성격 | 차분함 · 정밀함 · 손의 감각 · 편집자적 판단 |
| 목소리 | 짧은 동사, 현재형, 근거를 붙여 단정한다 |
| 금지 어휘 | 혁신적인, 강력한, "~하기 위해", 느낌표, ALL CAPS |

이름의 근거: 필름을 현상한 뒤 **콘택트 시트를 라이트테이블에 올려놓고 프레임을 고르던 행위**가 이 제품의 핵심 작업(생성 결과 검토 → 선택 → 승인 → 발행)과 정확히 같다.

---

## 2. 비주얼 세계 — "콘택트 시트"

결과물은 둥근 카드가 아니라 **프레임**이다.
프레임 번호, 얇은 테두리, 빨간 펜으로 그린 선택 표시, 직사각 승인 도장.
사용자의 주된 행동은 "더 만들기"가 아니라 **고르기와 승인하기**다.

## 3. 색 (기존 팔레트 미사용)

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `paper` | `#EFF0F2` | 작업대 배경 (차가운 회색, 크림 아님) |
| `sheet` | `#F8F8F7` | 프레임 시트 |
| `ink` | `#14171C` | 본문·제목·주 버튼 |
| `ink-2` | `#3A4048` | 보조 텍스트 |
| `muted` | `#767D87` | 메타·프레임 번호 |
| `rule` | `#D3D6DB` | 가는 구분선 |
| `rule-strong` | `#A8AEB7` | 강한 경계 |
| `mark` | `#C8402F` | **선택 표시·승인 도장에만** (빨간 펜) |
| `amber` | `#A9761B` | 비용·위험 맥락에만 |

그라데이션·네온·글래스·보라·청록 없음. 상태색은 배지가 아니라 **도장과 펜 자국**으로 표현한다.

## 4. 타이포

- Pretendard Variable — 본문과 제목. Display 600, 본문 400. **700 이상 금지.**
- JetBrains Mono — 프레임 번호(`F-014`), 타임코드(`00:00:03.000`), 비용, ID, 승인자.
- Display 자간 `-0.03em`. 한글 `word-break: keep-all`.
- 제목에서 단어 하나만 색칠하지 않음. ALL-CAPS 라벨 없음.

---

## 5. 레이아웃

```text
┌──┬──────────────────────────────┬──────────────┐
│  │ 작업표  프로젝트 / Provider / 비용 0원      │
│S0├──┬──┬──┬──┬──────────────────────┼──────────────┤
│S1│F │F │F │F │  선택된 프레임       │  검상 패널   │
│S2│0 │0 │0 │0 │  (빨간 펜 표시)      │  출처/권리   │
│..│1 │1 │2 │1 │                      │  비용/게이트 │
│S9│4 │5 │1 │7 │                      │  모듈 링크 0 │
└──┴──┴──┴──┴──────────────────────┴──────────────┘
 64px            1fr                     320px
```

- 좁은 코드 레일(64px): S0~S9 코드만 세로로. 활성 항목은 왼쪽 빨간 선.
- 중앙: 콘택트 시트(프레임 그리드). 상단 구분은 밑줄 탭.
- 우측: **검상 패널** — 선택된 프레임의 출처·권리·비용·게이트 상태.
- 최상단: **작업표** — 프로젝트 / Provider / 예상 비용 / 모듈 링크를 라벨:값으로.

## 6. 핵심 컴포넌트

| 컴포넌트 | 정의 |
|---|---|
| Frame | 얇은 테두리 + 프레임 번호 + 썸네일 영역 + 상태 도장 |
| Selection mark | 빨간 펜 타원. 선택된 프레임에만 겹쳐 표시 |
| Status stamp | `초안` / `검수` / `승인` / `보류` / `샘플` 직사각 도장 |
| Gate step | 4단계 게이트. 완료=검정 채움, 현재=빨간 선, 잠김=회색 |
| Job ticket | 상단 라벨:값 작업표 |
| Inspect panel | 선택 프레임의 메타데이터 행 |
| Ruled tab | 밑줄 탭. 알약형 탭 없음 |
| Ink button | 검정 사각 버튼 / 빨간 밑줄 텍스트 액션 |
| Field | 밑줄 입력칸. 둥근 입력칸 없음 |
| Empty frame | 빈 프레임 테두리 + "첫 프레임을 올리세요" |

## 7. 핵심 화면 2개

1. **S0 Collector** — 수집함을 콘택트 시트로. 프레임 선택 → 우측 검상 패널에 출처·権리·비용.
2. **S8 Video Workbench** — 상단 4게이트 스텝, 하단 샷 트랙, 우측 검상 패널에 `rights_flag`와 승인 도장.

## 8. 기존 디자인과의 단절

| 기존 (v1) | 신규 (v2) |
|---|---|
| 남색 그라데이션 사이드바 + 글래스 톱바 | 64px 코드 레일 + 작업표 |
| 4개 KPI 카드 + 스파크라인 | 프레임 그리드 + 선택 표시 |
| 보라·청록 그라데이션 버튼 | 검정 사각 버튼 + 빨간 펜 |
| ALL-CAPS 아이브로우, 가운뎃점 메타, 화살표 버튼 | 라벨:값 작업표, 동사형 버튼 |
| 같은 둥근 카드 반복 | 얇은 선으로 나눈 프레임과 검상 패널 |

## 9. Figma 연결 상태

이 세션에는 Figma MCP가 연결돼 있지 않습니다(사용 가능한 MCP 리소스 0건, Figma 도구 0건).
공식 Figma MCP는 쓰기 권한을 지원하지만 OAuth 연결이 필요합니다.
현재 산출물은 브라우저에서 열리는 `index.html` 디자인 보드이며, Figma 연결 후 프레임/컴포넌트 구조를 그대로 옮길 수 있도록 이름과 토큰을 명시했습니다.
